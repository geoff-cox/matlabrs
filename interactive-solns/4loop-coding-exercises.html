    (a)

    Write a function named powersOfTwo that uses fprintf and a for loop to compute and display the first \(n\) powers of 2.
    🔗
    Inputs:
    🔗
    n
    🔗
    (1x1) double
    🔗
    number of powers of 2 to display
    🔗
    Outputs:
    🔗
    None
    🔗
    display to command window with fprintf
    🔗
    Test Cases ⤵︎
    🔗
    fprintf("Test with n = 2:\n");
powersOfTwo(2)
fprintf("Test with n = 7:\n");
powersOfTwo(7)
    Expected ⤵︎
    🔗
    Test with n = 2:
2^1 = 2
2^2 = 4
Test with n = 7:
2^1 = 2
2^2 = 4
2^3 = 8
2^4 = 16
2^5 = 32
2^6 = 64
2^7 = 128
    Solution.
    Here is one possible solution:
    🔗
    function powersOfTwo(n)
	for k = 1:n
		fprintf('2^%d = %d\n', k, 2^k);
	end
end

    Inputs:
    🔗
    n
    🔗
    (1x1) double
    🔗
    non-negative integer

    Outputs:

    🔗
    m

    (1x1) double
    🔗
    multiple to sum
    🔗
    Outputs:
    🔗
    total
    🔗

	end
end

    (d)

    Write a function named prob3HeadsInARow that estimates the probability of flipping 3 heads when flipping a coin 3 times. Inside the loop, simulate three coin flips using three separate calls to randi([0,1]). Let 1 represents heads and 0 represents tails.
    🔗
    Inputs:
    🔗
    n
    🔗
    (1x1) double
    🔗
    number of times we flip 3 coins
    🔗
    Outputs:
    🔗
    prob
    🔗
    (1x1) double
    🔗
    probability of 3 heads in a row
    🔗
    Test Cases ⤵︎
    🔗
    rng(123);  % Set seed
prob = prob3HeadsInARow(10)
prob = prob3HeadsInARow(100)
prob = prob3HeadsInARow(1000)
    Expected ⤵︎
    🔗
    󠀠
% prob = 0.2000
% prob = 0.1300
% prob = 0.1200
    📝: What is rng(123)?
    Note: rng(123) sets the random seed (i.e., 123) to ensure that the same sequence of random numbers is generated each time, which allows for consistent test results. The seed value can be any integer.
    🔗
    Solution.
    Here is one possible solution:
    🔗
    function prob = prob3HeadsInARow(n)
	count_HHH = 0;
	for k = 1:n
		flip1 = randi([0, 1]);
		flip2 = randi([0, 1]);
		flip3 = randi([0, 1]);
		if flip1 == 1 && flip2 == 1 && flip3 == 1
			count_HHH = count_HHH + 1;
		end
	end
	prob = count_HHH / n;
end

    🔗

    starting balance
    🔗
    r

    (1x1) double

    monthly interest rate

    (f)

    An integer greater than 1 is prime if its only divisors are 1 and itself.
    🔗
    Write a function named isXPrime that tests whether a given positive integer is prime. Use a for loop and the mod function.
    🔗
    As a comment in your code (below HR statement), explain why it is enough to check divisors up to the square root of the number you are testing. Give an example to support your explanation.
    🔗
    Inputs:
    🔗
    x
    🔗
    (1x1) double
    🔗
    positive integer to test
    🔗
    Outputs:
    🔗
    tf
    🔗
    (1x1) logical
    🔗
    true if x is prime, false otherwise
    🔗
    Test Cases ⤵︎
    🔗
    answer = isXPrime(17)
answer = isXPrime(15)
answer = isXPrime(1)
answer = isXPrime(899321)
answer = isXPrime(215773)
    Expected ⤵︎
    🔗
    % answer = true
% answer = false
% answer = false
% answer = true
% answer = false
    Solution.
    Here is one possible solution:
    🔗
    function tf = isXPrime(x)
	if x <= 1
		tf = false;	% Edge case handling
		return
	end
	tf = true;	% Assume x is prime until we find a divisor
	for k = 2:sqrt(x)	% Check divisors up to sqrt(x)
		if mod(x, k) == 0
			tf = false;	% Found a divisor => x is not prime
			return
		end
	end
end
    📝: Why do we only Check Divisors Up to \(\sqrt{x}\text{?}\)
    Suppose we are testing whether 36 is prime. The proper divisors of 36 are (2, 18), (3, 12), (4, 9), and (6, 6). The square root of 36 is 6. All other pairs of divisors must include one divisor less than 6 and one greater than 6. Therefore, we don’t need to check 9 since 4 would have been found as a divisor.

    (g)

    Let \(p\) and \(N\) be positive integers, then
    • \(p\) is a proper divisor of \(N\) if \(p < N\) and \(p\) divides \(N\) evenly.
      Example: the proper divisors of 12 are 1, 2, 3, 4, and 6.
      🔗
      🔗
    🔗
    Write a function, called sumProperDivisors, that computes the sum of the proper divisors of a given positive integer, \(n\text{.}\) Use a for-loop and the mod function.
    🔗
    Inputs:
    🔗
    n
    🔗
    (1x1) double
    🔗
    positive integer
    🔗
    Outputs:
    🔗
    sum_divisors
    🔗
    (1x1) double
    🔗
    sum of proper divisors of n
    🔗
    Test Cases ⤵︎
    🔗
    out = sumProperDivisors(6)
out = sumProperDivisors(8)
out = sumProperDivisors(12)
out = sumProperDivisors(1)
    Expected ⤵︎
    🔗
    % out = 6 (1 + 2 + 3)
% out = 7 (1 + 2 + 4)
% out = 16 (1 + 2 + 3 + 4 + 6)
% out = 0 (no proper divisors)

    Here is one possible solution:
    🔗
    function sum_divisors = sumProperDivisors(n)
	sum_divisors = 0;
	for k = 1:(n-1) % Check all numbers less than n
		if mod(n, k) == 0
			sum_divisors = sum_divisors + k; % Found one, add it
		end
	end
end

    (h)

    Let \(p\) and \(N\) be positive integers, then
    • \(N\) is “perfect” if it equals the sum of its proper divisors.
      N = 6 is perfect because \(1 + 2 + 3 = 6\text{.}\)

    Write a function named approxE that takes a nonnegative integer n and returns the approximation
    \begin{equation*} e \approx 1 + \frac{1}{1!} + \frac{1}{2!} + \cdots + \frac{1}{n!}. \end{equation*}
    Use one for-loop.
    🔗
    Inputs:
    🔗
    n
    🔗
    (1x1) double
    🔗
    nonnegative integer
    🔗
    Outputs:
    🔗
    approx
    🔗
    (1x1) double
    🔗
    approximation of e using n terms
    🔗
    Test Cases ⤵︎
    🔗
    out = approxE(0)
out = approxE(1)

    function approx = approxE(n)
	approx = 1;
	factorial = 1; % To keep track of k!
	for k = 1:n
		factorial = factorial * k; % Update factorial to k!
		approx = approx + 1/factorial; % Add 1/k!
	end
end

    (j)

    The following (partial) sum converges to \(e^x\) as \(N \to \infty\text{:}\)
    \begin{equation*} \sum_{k=0}^{N} \frac{x^k}{k!} = 1 + \frac{x}{1!} + \frac{x^2}{2!} + \cdots + \frac{x^N}{N!} \end{equation*}
    🔗
    So for large \(N\) this series can be used to approximate \(e^x\text{:}\)
    \begin{equation*} e^x \approx 1 + \frac{x}{1!} + \frac{x^2}{2!} + \cdots + \frac{x^N}{N!} \end{equation*}
    for any real number \(x\text{.}\)
    🔗
    Write a function named approxEofx that takes a real number x and a positive integer N and returns the approximation of \(e^x\) using the series above. Use one for-loop.
    🔗
    Inputs:
    🔗
    x
    🔗
    (1x1) double
    🔗
    real number
    🔗
    N
    🔗
    (1x1) double
    🔗
    positive integer
    🔗
    Outputs:
    🔗
    approx
    🔗
    (1x1) double
    🔗
    approximation of \(e^x\) using \(N\) terms
    🔗
    Test Cases ⤵︎
    🔗
    out = approxEofx(0, 10)
out = approxEofx(1, 10)
out = approxEofx(2, 20)
    Expected ⤵︎
    🔗
    % out = 1 (e^0 = 1)
% out ≈ 2.7183 (approximates e^1)
% out ≈ 7.3891 (approximates e^2)
    Solution.
    Here is one possible solution:
    🔗
    function approx = approxEofx(x, N)
	approx = 1;
	factorial = 1; % To keep track of k!
	for k = 0:N
		if k > 0
			factorial = factorial * k; % Update factorial to k!
		end
		approx = approx + (x^k)/factorial; % Add x^k/k!
	end
end

    (k)

    Write a function, binomialCoeff, that computes \(n\) choose \(m\) (the binomial coefficient) using the formula:
    \begin{equation*} \binom{n}{m} = \frac{n!}{m!(n-m)!}\text{.} \end{equation*}
    Use a for loop. Assume \(n\) is a nonnegative integer and \(m\) is a non-negative integer less than or equal to \(n\text{.}\)
    🔗
    To code this with one for loop, expand \(n!\) down to \((n-m)!\text{:}\)
    \begin{equation*} n(n-1)(n-2)\cdots(n-(m-1))(n-m)! \end{equation*}
    then cancel the \((n-m)!\) in the numerator and denominator to get:
    \begin{equation*} \binom{n}{m} = \frac{n(n-1)(n-2)\cdots(n-(m-1))}{m(m-1)(m-2)\cdots 1} \end{equation*}
    But this is the same as:
    \begin{equation*} \binom{n}{m} = \frac{n}{m}\cdot\frac{n-1}{m-1}\cdot\frac{n-2}{m-2}\cdots\frac{n-(m-1)}{1} \end{equation*}
    This way, you can compute each fraction for \(k=0,1,2,\ldots,m-1\text{.}\)
    🔗
    Inputs:
    n (1x1) double — nonnegative integer
    🔗
    m (1x1) double — non-negative integer less than or equal to \(n\)
    🔗
    Outputs:
    bicoeff (1x1) double — the binomial coefficient \(\binom{n}{m}\)
    🔗
    Test Cases ⤵︎
    🔗
    bcoef = binomialCoeff(5, 2)
bcoef = binomialCoeff(0, 0)
bcoef = binomialCoeff(7, 7)
bcoef = binomialCoeff(10, 3)
    Expected ⤵︎
    🔗
    % bcoef = 10 (5!/(2!*(5-2)!))
% bcoef = 1 (0!/(0!*0!))
% bcoef = 1 (7!/(7!*0!))
% bcoef = 120 (10!/(3!*7!))
    Solution.
    Here is one way to compute the binomial coefficient using a for loop:
    🔗
    function F = binomialCoeff(n, m)
	numerator = 1;
	denominator = 1;

	for k = 0:(m-1)
		numerator = numerator * (n - k);
		denominator = denominator * (m - k);
	end

	F = numerator / denominator;
end

    (l)

    Write a function named countRunsOfOnes that simulates n single coin flips using randi([0,1]) and returns the number of runs of one or more consecutive heads.
    🔗
    Before you start coding, think about what information you need to count the runs. It is less than you might expect. You may find it helpful to write out some sequences of coin flips and count the runs by hand.
    🔗
    For example,
    • the flip sequence 0 1 1 0 1 0 1 1 1 contains 3 runs of heads.
      🔗
    • the flip sequence 1 1 0 0 1 1 1 0 contains 2 runs of heads.
      🔗
    • the flip sequence 0 0 0 0 contains 0 runs of heads.
      🔗
    • the flip sequence 1 1 1 1 1 1 contains 1 run of heads.
      🔗
    🔗
    Inputs:
    🔗
    n
    🔗
    (1x1) double
    🔗
    number of coin flips
    🔗
    Outputs:
    🔗
    runs
    🔗
    (1x1) double
    🔗
    number of runs of consecutive heads
    🔗
    Test Cases ⤵︎
    🔗
    rng(123);  % Set seed
runs = countRunsOfOnes(10)
runs = countRunsOfOnes(100)
runs = countRunsOfOnes(600)
runs = countRunsOfOnes(0)
    Expected ⤵︎
    🔗
    󠀠
% runs = 3
% runs = 20
% runs = 160
% runs = 0 (no flips)
    Solution.
    Here is one possible solution:
    🔗
    function runs = countRunsOfOnes(n)
	runs = 0;
	prev = 0;
	for k = 1:n
		cur = randi([0,1]);
		if cur == 1 && prev == 0
			runs = runs + 1;
		end
		prev = cur;
	end
end

    Write a function named longestHeadRun that simulates n single coin flips using randi([0,1]) and returns the length of the longest run of consecutive heads. If n = 0, return 0.

    For example,
    • the longest head run of the sequence 1 0 1 1 1 0 1 is 3.

    function yf = moveInYsDirection(y0, xf, h)
	x = 0;
	y = y0;

	numSteps = ceil(xf / h);

	for i = 1:numSteps
		slope = 2*y - 2*x*y;  % Compute slope at current point
		[x, y] = movePoint(x, y, slope, h);  % Move to next point
	end

	yf = y;  % Final approximation of y(xf)
end
