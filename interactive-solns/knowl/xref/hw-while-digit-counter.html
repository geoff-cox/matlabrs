Task 1.h. Digit Counter.

Write a function called digitCount() that returns the number of digits in a positive integer n.
🔗
Use a while-loop performs the following for each iteration:
  • Extract the rightmost digit as the remainder from dividing by 10.
    🔗
  • Remove the rightmost digit by dividing by 10 and rounding down.
    🔗
The number of iterations gives the digit count.
🔗
Inputs:
n
🔗
(1x1) double
🔗
positive integer
🔗
Outputs:
ct
🔗
(1x1) double
🔗
number of digits in n
🔗
Test Cases ⤵︎
🔗
ct = digitCount(123)
ct = digitCount(9999)
ct = digitCount(7)
ct = digitCount(10001)
Expected ⤵︎
🔗
ct = 3
ct = 4
ct = 1
ct = 5
Solution.
function ct = digitCount(n)
	ct = 0;

	while n > 0
		ct = ct + 1;
		n = floor(n / 10);
	end
end
