    1. Conceptual Questions.

    (a)

    Which loop header generates the k-values: 3, 6, 9, 12, 15?
    🔗
    • for k = [3, 6, 9, 12, 15]
    • for k = 1:3:15
    • for k = 3:6:15
    • for k = 3:2:15
    • for k = 3:3:15
    🔗

    (b)

    What are the k-values generated by the loop header: for k = 4:-2:-3?
    🔗
    • 4, 2, 0, -2, -4
    • With a step of -2, the next value after -2 would be -4, which overshoots past -3, so it is not included.
    • 4, 2, 0, -2
    • Start at 4 and subtract 2 each time. The next value would be -4, which goes past the stop value -3, so the loop ends at -2.
    • 4, 2, 0, -2, -3
    • -3 is the stop value, but it is only included if the step lands on it exactly.
    • 2, 0, -2
    • The start value 4 is missing.
    🔗

    6. Counting Die Rolls.

    (a)

    Write a function named highDieCount that uses a for loop to count the number of times a 5 or 6 is rolled when rolling a six-sided die n times. Inside the loop, simulate a die roll using randi([1,6]), which returns a random integer between 1 and 6.
    🔗
    Inputs:
    🔗
    n
    🔗
    (1x1) double
    🔗
    number of die rolls
    🔗
    Outputs:
    🔗
    count
    🔗
    (1x1) double
    🔗
    the number of times 5 or 6 is rolled
    🔗
    		 
    % Write your highDieCount function here. You must use a for-loop.
function count = highDieCount(n)
	count = 0;
	for k = 1:n
		roll = randi([1,6]);
		if roll == 5 || roll == 6
			count = count + 1;
		end
	end
end

    Write a function named snakeEyesCount that counts the number of times you roll two 1’s in a row in n rolls.
    🔗
    Inputs:
    🔗
    n
    🔗
    (1x1) double
    🔗
    number of die rolls
    🔗

    🔗

function count = snakeEyesCount(n)
	count = 0;
	prevRoll = 0;
	for k = 1:n
		roll = randi([1,6]);
		if roll == 1 && prevRoll == 1
			count = count + 1;
		end
		prevRoll = roll;
	end
end

    7. Code Recall.

    Use the functions below to answer the questions that follow. Assume that the functions are defined in the same file and that is_valid_triangle correctly identifies valid triangles.
    🔗
    function result=my_xor_threeway(a,b,c)
if a==true
	result=1;
elseif b==true
	result=1;
elseif c==true
	result=1;
else
	result=0;
end
end

    function type=classify_triangle(a,b,c)
if is_valid_triangle(a,b,c)==true
	if a==b && b==c
		type='Equilateral'
	elseif my_xor_threeway(a==b,b==c,a==c)
		type='Isosceles'
	elseif a~=b && b~=c
		type='Scalene'
	end
elseif is_valid_triangle(a,b,c)==false
	type='Invalid'
end
end

    (a)

    Which statement best explains why my_xor_threeway correctly detects isosceles triangles inside classify_triangle?
    🔗
    • Because my_xor_threeway correctly implements xor.
    • Because for valid triangles, at most one of a==b, b==c, a==c can be true.
    • Because my_xor_threeway specifically checks the isosceles case.
    • Because after ruling out equilateral, the isosceles case reduces to checking whether at least one pair of sides is equal.
    • Because if the equilateral branch fails, all three a==b, b==c, a==c must be false
    🔗
