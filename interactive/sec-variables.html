    Section 1.4 Variables

    A variable in MATLAB is a named location in memory that stores a value. Variables allow you to save data so that it can be reused, modified, and combined with other data as a program runs. Every calculation you perform in the Command Window produces values, and variables allow you to store those values for later use.
    🔗
    At any moment, MATLAB keeps track of all defined variables in an internal memory area called the workspace. You can view these variables in the Workspace panel of the MATLAB Desktop.
    🔗

    Variable Assignment in MATLAB.

    Syntax: variable_name = expression
    🔗
    Key rules:
    • The expression on the right-hand side is evaluated first; the result is stored under the name on the left-hand side.
      🔗
    • Variable names must start with a letter, may contain letters, digits, and underscores, and cannot be a MATLAB keyword.
      🔗
    • Names are case-sensitive: Area and area are different variables.
      🔗
    • Ending a line with a semicolon ; suppresses output in the Command Window but still creates the variable.
      🔗
    • MATLAB stores the computed value, not the formula; changing one variable does not automatically update others that were computed from it.
      🔗
    🔗
    🔗

    🌌 Example 1.16. Basic Variable Assignment.

    Define the variables a and b with values 1 and 7.8, and suppress the output of b.
    🔗
    a = 1
b = 7.8;
    After running these commands:
    • Both a and b appear in the Workspace with their assigned values.
      🔗
    • Only the value of a is printed in the Command Window because b ends with a semicolon.
      🔗
    🔗
    🔗

    🌌 Example 1.17. Using Multiple Variables in a Computation.

    A triangle has a base of 4 and a height of 10. Store each measurement in a variable and compute the area.
    🔗
    base   = 4;
height = 10;
area   = 0.5 * base * height
    MATLAB displays area = 20. The variables base and height remain in the workspace unchanged. If you now run base = 6; the value of area stays at 20 because MATLAB stored the result, not the formula.
    🔗
    🔗

    🌌 Example 1.18. Valid and Descriptive Variable Names.

    The following code uses descriptive names to compute the total cost of a full tank of gas.
    🔗
    pricePerGallon = 3.11;
tankCapacity   = 15;
fullTankCost   = pricePerGallon * tankCapacity
    Each name starts with a letter, uses only letters and digits (mixed case), avoids MATLAB keywords, and clearly describes the stored value. Compare this to naming the variables x, y, z: the descriptive version is far easier to read and debug.
    🔗
    The following names are invalid and cause an error:
    • 3sides — starts with a digit.
      🔗
    • tank-capacity — contains a hyphen (interpreted as minus).
      🔗
    • end — is a reserved MATLAB keyword.
      🔗
    🔗
    🔗

    Checkpoint 1.20. Reading Questions.

    (a)

      In MATLAB, the symbol = means the same thing as in a math equation.
      🔗

    • True.

    • In MATLAB, = is the assignment operator. It instructs MATLAB to evaluate the right-hand side and store the result under the left-hand name. It does not represent a mathematical equality.

    • False.

    • In MATLAB, = is the assignment operator. It instructs MATLAB to evaluate the right-hand side and store the result under the left-hand name. It does not represent a mathematical equality.
    🔗

    (b)

    What happens when you end a MATLAB assignment statement with a semicolon?
    🔗
    • The variable is not created in the workspace.
    • The variable is still created; the semicolon only affects display.
    • The variable is created, but its value is not printed in the Command Window.
    • Correct! The semicolon suppresses Command Window output while the variable is still stored.
    • The variable is created with an empty value.
    • The expression is fully evaluated; the semicolon only suppresses display.
    • The assignment applies only to the current session and is not saved.
    • Variables persist in the workspace until cleared or MATLAB is closed, regardless of semicolons.
    🔗

    (c)

    After running area = 0.5 * base * height;, you reassign base = 10. What is the new value of area?
    🔗
    • It stays the same — MATLAB does not recompute area automatically.
    • Correct! MATLAB stored the numeric result, not the formula. Changing base has no effect on area.
    • It is updated automatically because base changed.
    • MATLAB stores values, not formulas. Reassigning base does not trigger a recomputation of area.
    • MATLAB throws an error because base was already used.
    • Variables can be freely reassigned. No error occurs.
    • The value of area becomes undefined.
    • area retains the value computed from the original base and height.
    🔗

    (d)

    A student types the following:
    🔗
    result = 8 * 3;
    What is true about this command?
    🔗
    • The variable result is created with value 24, but nothing is displayed in the Command Window.
    • Correct. The semicolon suppresses output. The variable is created and stored, but the display is silent.
    • The variable result is not created because of the semicolon.
    • A semicolon does not prevent variable creation. It only suppresses the display.
    • The variable result is created and result = 24 is displayed.
    • The semicolon suppresses the display. The variable is created but not shown.
    • MATLAB displays an error because of the missing output.
    • A semicolon is valid MATLAB syntax. No error is produced.
    🔗

    (e)

    Which of the following is a valid MATLAB variable name?
    🔗
    • 2ndValue
    • Variable names must start with a letter, not a digit.
    • value2nd
    • Correct! It starts with a letter and contains only letters and digits.
    • end
    • end is a reserved MATLAB keyword and cannot be used as a variable name.
    • my-value
    • Hyphens are not allowed in variable names; MATLAB would interpret - as subtraction.
    🔗

    (f)

    After running the two lines below, what is the value of result?
    🔗
    x = 4;
result = x * 3;
x = 10;
    • 12
    • Correct! result was computed when x = 4. Changing x afterward has no effect.
    • 30
    • MATLAB does not recompute result when x changes later.
    • 10
    • result stores the product x * 3 evaluated at the time of the assignment.
    • An error occurs.
    • No error; all three lines are valid MATLAB assignments.
    🔗

    (g)

    What is the purpose of the MATLAB workspace?
    🔗
    • It stores all currently defined variables and their values.
    • Correct! The workspace is MATLAB’s in-memory record of all active variables.
    • It saves MATLAB scripts to disk automatically.
    • The workspace holds variables in memory; saving scripts requires explicit file operations.
    • It displays Command Window output history.
    • That is the role of the Command Window itself, not the workspace panel.
    • It manages MATLAB’s toolbox licenses.
    • License management is handled elsewhere. The workspace stores variables.
    🔗

    (h)

    Which command lists all MATLAB reserved keywords?
    🔗
    • iskeyword
    • Correct! Running iskeyword with no argument returns the full list of reserved keywords.
    • keywords
    • This is not a standard MATLAB command. Use iskeyword.
    • whos
    • whos lists workspace variables, not keywords.
    • help reserved
    • There is no reserved help topic. Use iskeyword.
    🔗

    (i)

    Which of the following best describes why descriptive variable names are recommended?
    🔗
    • They make code easier to read, understand, and debug.
    • Correct! Names like tankRadius immediately convey meaning; names like r do not.
    • They make MATLAB execute code faster.
    • Variable name length has no effect on execution speed.
    • They prevent accidental reassignment of variables.
    • MATLAB does not restrict reassignment based on name style.
    • They allow MATLAB to auto-generate documentation.
    • MATLAB does not automatically generate documentation from variable names.
    🔗

    (j)

    Are Temperature and temperature the same variable in MATLAB?
    🔗
    • Yes, MATLAB ignores capitalization in variable names.
    • MATLAB is case-sensitive; capitalization matters.
    • No, MATLAB variable names are case-sensitive.
    • Correct! Temperature and temperature are two distinct variables.
    • It depends on the operating system.
    • Case sensitivity is a MATLAB language rule, independent of the OS.
    • They are the same if they hold the same value.
    • Names are compared character by character; values are irrelevant to naming.
    🔗

    (k)

      A variable created with a semicolon at the end of the line still appears in the MATLAB workspace.
      🔗

    • True.

    • True. The semicolon only suppresses Command Window output; the variable is fully created and stored in the workspace.

    • False.

    • True. The semicolon only suppresses Command Window output; the variable is fully created and stored in the workspace.
    🔗

    (l)

      In MATLAB, writing area = base * height creates a dynamic link so that area updates automatically whenever base or height changes.
      🔗

    • True.

    • False. MATLAB evaluates the right-hand side once at the time of the assignment and stores the resulting number. No dynamic link is maintained.

    • False.

    • False. MATLAB evaluates the right-hand side once at the time of the assignment and stores the resulting number. No dynamic link is maintained.
    🔗

      A variable name in MATLAB can begin with an underscore.
      🔗

    • True.

    • False. MATLAB variable names must begin with a letter. An underscore is allowed within the name but not as the first character.

    • False.

    • False. MATLAB variable names must begin with a letter. An underscore is allowed within the name but not as the first character.

    Checkpoint 1.21. Coding Exercises.

    (a) Speed, Distance, and Time.

    Use the MATLAB command window to assign values to variables for a car’s speed and travel time, then compute the distance traveled using \(d = s \cdot t\text{.}\)
    🔗
    Use the variable names speed, time, and distance.
    🔗
    Test your work with speed = 60 and time = 2.5. Your result should be distance = 150.
    🔗
    Solution. 
    speed = 60;
time = 2.5;
distance = speed * time
    🔗
    🔗

    (b) Celsius to Fahrenheit.

    Use the MATLAB command window to assign a temperature in Celsius to a variable, then convert it to Fahrenheit using the formula \(F = \frac{9}{5}C + 32\text{.}\)
    🔗
    Use the variable names tempC and tempF.
    🔗
    Test your work with tempC = 100. Your result should be tempF = 212.
    🔗
    Solution. 
    tempC = 100;
tempF = (9/5) * tempC + 32
    🔗
    🔗

    (c) Compound Interest.

    Use the MATLAB command window to assign values for the principal, interest rate, and number of years, then compute the balance using \(A = P(1 + r)^n\text{.}\)
    🔗
    Use the variable names principal, rate, years, and balance.
    🔗
    Test your work with principal = 1000, rate = 0.05, and years = 3. Your result should be approximately balance = 1157.625.
    🔗
    Solution. 
    principal = 1000;
rate = 0.05;
years = 3;
balance = principal * (1 + rate)^years
    🔗
    🔗

    (d) Area and Perimeter of a Rectangle.

    Use the MATLAB command window to assign values for the length and width of a rectangle, then compute both its area and perimeter.
    🔗
    Use descriptive variable names, like rectLen, rectWid, rectArea, and rectPerim.
    🔗
    Test your work with \(\ell = 5\) and \(w = 3\text{.}\)
    🔗
    Your results should be rectArea = 15 and rectPerim = 16.
    🔗
    Solution. 
    rectLen = 5;
rectWid = 3;
rectArea = rectLen * rectWid
rectPerim = 2 * (rectLen + rectWid)
    🔗
    🔗

    (e) Volume & Surface Area of a Cylinder.

    Use the MATLAB command window to assign values for the radius and height of a cylinder, then compute its volume and surface area.
    🔗
    The volume and surface area of a cylinder is given by:
    \begin{equation*} V = \pi r^2 h, \qquad S = 2\pi r h + 2\pi r^2 \end{equation*}
    Use pi for \(\pi\) and use descriptive variable names.
    🔗
    Test your work with \(r = 1.2\) and \(h = 3.5\text{.}\)
    🔗
    🔗
    Solution. 
    radius = 1.2;
height = 3.5;
volume = pi * radius^2 * height
surfaceArea = 2 * pi * radius * height + 2 * pi * radius^2
    🔗
    🔗

    (f) Kinetic Energy.

    Use the MATLAB command window to assign values for an object’s mass and velocity, then compute its kinetic energy using \(KE = \frac{1}{2}mv^2\text{.}\)
    🔗
    Use the variable names mass, velocity, and kineticEnergy.
    🔗
    Test your work with mass = 2 and velocity = 3. Your result should be kineticEnergy = 9.
    🔗
    Solution. 
    mass = 2;
velocity = 3;
kineticEnergy = 0.5 * mass * velocity^2
