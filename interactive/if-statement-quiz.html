    Reading Questions 📖 Reading Quiz

    1. Answer the Following Questions Related to If-Statements.

    (a) If Statement Requirements.

      Every if statement in MATLAB must end with the keyword end.
      🔗

    • True.

    • Correct! The end keyword is required to close every if statement, whether it contains just an if block, an if-else, or an if-elseif-else chain.

    • False.

    • Correct! The end keyword is required to close every if statement, whether it contains just an if block, an if-else, or an if-elseif-else chain.
    🔗

    (b) Else Branch Requirement.

      An else branch is required in every if statement.
      🔗

    • True.

    • Incorrect. The else branch is optional. If you only need to run code when a logical expression is true, you can use just an if block without an else.

    • False.

    • Incorrect. The else branch is optional. If you only need to run code when a logical expression is true, you can use just an if block without an else.
    🔗

    (c) Elseif Chain Evaluation Order.

    In an if-elseif-else chain, how does MATLAB determine which block to execute?
    🔗
    • MATLAB checks all logical expressions and runs the block with the highest priority.
    • Incorrect. MATLAB evaluates logical expressions in order from top to bottom and stops at the first true statement.
    • MATLAB checks logical expressions from top to bottom and runs the first true block.
    • Correct! Once MATLAB finds a true logical expression, it executes that block and skips all remaining branches.
    • MATLAB checks all logical expressions and runs all blocks whose statements are true.
    • Incorrect. Only one block executes in an if-elseif-else chain, even if multiple logical expressions are true.
    • MATLAB evaluates logical expressions randomly.
    • Incorrect. Logical expressions are always evaluated in the order they appear in the code.
    🔗

    (d) How Many Blocks Execute?

    Given this code:
    🔗
    x = 10;
if x > 5
	y = 1;
elseif x > 8
	y = 2;
elseif x > 3
	y = 3;
else
	y = 0;
end
    What is the value of y after this code executes?
    🔗
    • y = 2
    • Incorrect. The first logical expression (x > 5) is true, so MATLAB never checks the second logical expression.
    • y = 3
    • Incorrect. The first logical expression (x > 5) is true, so MATLAB never checks the third logical expression.
    • y = 6 (sum of 1+2+3)
    • Incorrect. Only one block executes in an if-elseif-else chain. The blocks don’t accumulate.
    • y = 1
    • Correct! Even though x > 8 and x > 3 are also true, MATLAB stops at the first true logical expression (x > 5) and assigns y = 1.
    🔗

    (e) Nested If vs Elseif Chain.

    What is the main difference between using nested if statements and using an if-elseif chain?
    🔗
    • There is no difference; they are equivalent in all cases.
    • Incorrect. Nested if statements can check multiple conditions independently, while elseif chains are mutually exclusive.
    • Nested if statements run faster than elseif chains.
    • Incorrect. Performance is not the key difference; the distinction is in the logic structure and whether branches are mutually exclusive.
    • Nested if statements can allow multiple blocks to execute; elseif chains execute only one block.
    • Correct! In an if-elseif-else chain, only one block runs. With nested if statements, multiple independent conditions can be true.
    • Elseif chains require more end keywords than nested if statements.
    • Incorrect. Actually, nested if statements require more end keywords (one for each if), while an elseif chain needs only one.
    🔗

    (f) If Statement Condition Type.

    Consider this code:
    🔗
    x = 5;
if x
	disp('x is true')
else
	disp('x is false')
end
    What will be displayed, and why?
    🔗
    • x is true, because any non-zero number is treated as true.
    • Correct! In MATLAB, non-zero values are treated as true in logical expressions, and zero is treated as false.
    • x is false, because x is not a logical value.
    • Incorrect. While x is numeric, MATLAB automatically converts non-zero numbers to true in logical expressions.
    • An error occurs because x is not a logical value.
    • Incorrect. MATLAB allows numeric values in if conditions and treats non-zero as true and zero as false.
    • x is false, because 5 is not equal to true.
    • Incorrect. MATLAB doesn’t compare x to true; it converts non-zero values to true.
    🔗

    (g)

    Every MATLAB if block must be closed with which keyword?
    🔗
    • end
    • Correct. end closes the if block.
    • endif
    • MATLAB uses end, not endif.
    • stop
    • stop is not a MATLAB keyword for closing blocks.
    • done
    • MATLAB uses end to close all control structures.
    🔗

    (h)

    In an if/elseif/else chain, how many branches execute when the first condition is true?
    🔗
    • Only the first true branch executes.
    • Correct. MATLAB evaluates top to bottom and executes only the first matching branch.
    • All true branches execute.
    • No — once a true branch is found, the rest are skipped.
    • The last matching branch executes.
    • MATLAB takes the first match, not the last.
    • Both the matching branch and the else branch execute.
    • The else branch only runs when no condition is true.
    🔗

    (i)

    In MATLAB, a condition is considered false when it evaluates to:
    🔗
    • Zero (0).
    • Correct. Zero is false; any nonzero value is true.
    • The string 'false'.
    • MATLAB uses numeric 0/1 for logical values, not strings.
    • An empty matrix [].
    • An empty matrix is also treated as false, but the most common false value is 0.
    • A negative number.
    • Any nonzero number — positive or negative — is true in MATLAB.
    🔗

    (j)

    What is printed by the following code?
    🔗
    x = 5;
if x > 10
    disp('big')
elseif x > 3
    disp('medium')
else
    disp('small')
end
    • medium
    • Correct. x = 5 is not greater than 10, but is greater than 3.
    • big
    • 5 > 10 is false.
    • small
    • The else only runs when both conditions are false.
    • Both medium and small are printed.
    • Only the first true branch executes.
    🔗

    (k)

      In MATLAB, only the value 1 is treated as true in an if condition.
      🔗

    • True.

    • False. Any nonzero value is treated as true.

    • False.

    • False. Any nonzero value is treated as true.
    🔗

    (l)

    How many elseif clauses may appear in a single if statement?
    🔗
    • Any number.
    • Correct. There is no limit on elseif clauses.
    • At most one.
    • You may chain as many elseif clauses as needed.
    • At most two.
    • No such limit exists.
    • Zero.
    • elseif is optional but you may include many.
    🔗

    (m)

    What happens if none of the conditions in an if/elseif chain are true and there is no else clause?
    🔗
    • No code in the if block executes; execution continues after end.
    • Correct. The block is simply skipped.
    • MATLAB throws an error.
    • No error occurs; the block is just skipped.
    • The first branch executes by default.
    • Branches only execute when their condition is true.
    • The last branch executes by default.
    • Without an else, nothing runs if all conditions are false.
    🔗

    (n)

    The correct MATLAB spelling for a secondary condition in an if chain is:
    🔗
    • elseif
    • Correct. Written as one word in MATLAB.
    • else if
    • Two words creates a nested if rather than an elseif chain.
    • elif
    • That is Python syntax, not MATLAB.
    • elsif
    • That is Ruby syntax, not MATLAB.
    🔗

      else if (two words) and elseif (one word) are interchangeable in MATLAB.
      🔗

    • True.

    • False. else if opens a nested if block requiring its own end; elseif is part of the same block.

    • False.

    • False. else if opens a nested if block requiring its own end; elseif is part of the same block.
