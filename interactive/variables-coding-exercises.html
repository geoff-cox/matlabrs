    1. Speed, Distance, and Time.

    Write a MATLAB script that stores a car’s speed and travel time in variables, then computes the distance traveled using \(d = s \cdot t\text{.}\)
    🔗
    Inputs:
    speed
    🔗
    (1x1) double
    🔗
    speed in miles per hour
    🔗
    time
    🔗
    (1x1) double
    🔗
    travel time in hours
    🔗
    Outputs:
    distance
    🔗
    (1x1) double
    🔗
    distance traveled in miles
    🔗
    Test with speed = 60 and time = 2.5; the result should be distance = 150.
    🔗
    Solution.
    speed	= 60;
time	 = 2.5;
distance = speed * time
    🔗
    🔗

    2. Celsius to Fahrenheit.

    Convert a temperature from Celsius to Fahrenheit using the formula \(F = \tfrac{9}{5}C + 32\text{.}\)
    🔗
    Inputs:
    tempC
    🔗
    (1x1) double
    🔗
    temperature in degrees Celsius
    🔗
    Outputs:
    tempF
    🔗
    (1x1) double
    🔗
    temperature in degrees Fahrenheit
    🔗
    Test with tempC = 100; the result should be tempF = 212.
    🔗
    Solution.
    tempC = 100;
tempF = (9/5) * tempC + 32
    🔗
    🔗

    3. Compound Interest — One Period.

    Compute the balance after one year of compound interest using \(A = P(1 + r)^n\text{,}\) where \(P\) is the principal, \(r\) is the annual interest rate, and \(n\) is the number of years.
    🔗
    Inputs:
    principal
    🔗
    (1x1) double
    🔗
    initial deposit in dollars
    🔗
    rate
    🔗
    (1x1) double
    🔗
    annual interest rate (e.g., 0.05 for 5%)
    🔗
    years
    🔗
    (1x1) double
    🔗
    number of years
    🔗
    Outputs:
    balance
    🔗
    (1x1) double
    🔗
    account balance after the given years
    🔗
    Test with principal = 1000, rate = 0.05, years = 3; the result should be approximately balance = 1157.6.
    🔗
    Solution.
    principal = 1000;
rate		= 0.05;
years	 = 3;
balance	 = principal * (1 + rate)^years
    🔗
    🔗

    4. Area and Perimeter of a Rectangle.

    Given the length and width of a rectangle, compute both its area and perimeter using descriptively named variables.
    🔗
    Inputs:
    rectLen
    🔗
    (1x1) double
    🔗
    length of the rectangle
    🔗
    rectWid
    🔗
    (1x1) double
    🔗
    width of the rectangle
    🔗
    Outputs:
    rectArea
    🔗
    (1x1) double
    🔗
    area of the rectangle
    🔗
    rectPerim
    🔗
    (1x1) double
    🔗
    perimeter of the rectangle
    🔗
    Test with rectLen = 5 and rectWid = 3; results should be rectArea = 15 and rectPerim = 16.
    🔗
    Solution.
    rectLen	 = 5;
rectWid	 = 3;
rectArea	= rectLen * rectWid
rectPerim = 2 * (rectLen + rectWid)
    🔗
    🔗

    5. Kinetic Energy.

    Compute the kinetic energy of a moving object using \(KE = \tfrac{1}{2}mv^2\text{.}\)
    🔗
    Inputs:
    mass
    🔗
    (1x1) double
    🔗
    mass of the object in kilograms
    🔗
    velocity
    🔗
    (1x1) double
    🔗
    speed of the object in meters per second
    🔗
    Outputs:
    kineticEnergy
    🔗
    (1x1) double
    🔗
    kinetic energy in joules
    🔗
    Test with mass = 2 and velocity = 3; the result should be kineticEnergy = 9.
    🔗
    Solution.
    mass			= 2;
velocity		= 3;
kineticEnergy = 0.5 * mass * velocity^2
