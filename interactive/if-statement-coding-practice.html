    Use the coding area to complete the each task. Some tasks build on the previous one, so copy and modify your code block as you go.

    (a) Define y.

    After completing each part, click Evaluate to see the results. For parts 3 & 4, click Evaluate multiple times to see how the results change based on the random value of x.
    🔗
    Part 1
    🔗
    Define the variable x as 6.
    🔗
    Define the variable y as 1 if x is less than or equal to 9, otherwise set y to 4.
    🔗
    Part 2
    🔗
    Change x to 16.
    🔗
    Part 3
    🔗
    Change x to be a random integer between -5 and 15 using randi([-5, 15]).
    🔗
    Part 4
    🔗
    Update your if statement so that it sets y to 1 if
    🔗
    x is between 1 and 9 (inclusive), otherwise set y to 4.
    🔗
    Solution 1. Part 1 
    %─── TYPE YOUR CODE HERE ───%
x = 6;
if x <= 9
	y = 1;
else
	y = 4;
end
%───────────────────────────%
fprintf('for x = %d, we set y to %d\n', x, y);
    🔗
    Solution 2. Part 4 
    %─── TYPE YOUR CODE HERE ───%
x = randi([-5, 15]);
if x >= 1 & x <= 9
	y = 1;
else
	y = 4;
end
%───────────────────────────%
fprintf('for x = %d, we set y to %d\n', x, y);

    (b) Updating a Variable.

    Suppose n is a random integer between 0 and 20. Give the code that
    • increases n by 5 if it is greater than 10,
      🔗
    • decreases n by 5 if it is less than 10, and
      🔗
    • sets n to 1 if it is equal to 10.
      🔗
    🔗
    Solution. 
    n = randi([0, 20]);
fprintf('Starting n = %d\n', n);
%─── TYPE YOUR CODE HERE ───%
if n > 10
	n = n + 5;
elseif n < 10
	n = n - 5;
else
	n = 1;
end
%───────────────────────────%
fprintf('Updated n = %d\n', n);
    🔗

    2. Writing Functions with if Statements.

    For each, write a function that uses conditionals.
    🔗

    (a) Sign Label (part 1).

    Create a function named sign_label that takes one input x and returns one output label with the value 'positive', 'negative', or 'zero'.
    🔗
    Solution. 
    function label = sign_label(x)
	if x > 0
		label = 'positive';
	elseif x < 0
		label = 'negative';
	else
		label = 'zero';
	end
end
    🔗
    🔗

    (b) Sign Label (part 2).

    Modify the function so it returns a second output named code with values 1, -1, or 0 that match the sign.
    🔗
    Solution. 
    function [label, code] = sign_label(x)
	if x > 0
		label = 'positive';
		code = 1;
	elseif x < 0
		label = 'negative';
		code = -1;
	else
		label = 'zero';
		code = 0;
	end
end
    🔗
    🔗

    (c) Freeze Alert (part 1).

    Write a function named freeze_alert that takes tempC (a scalar temperature in Celsius) and tempWarn (how close to freezing to warn) and returns message. If tempC is at or below tempWarn, return 'Freeze warning'; otherwise return 'No warning'.
    🔗
    Solution. 
    function message = freeze_alert(tempC, tempWarn)
	if tempC <= tempWarn
		message = 'Freeze warning';
	else
		message = 'No warning';
	end
end
    🔗
    🔗

    (d) Freeze Alert (part 2).

    Update the function to return a second output isFreezing that is true or false along with the message.
    🔗
    Solution. 
    function [message, isFreezing] = freeze_alert(tempC, tempWarn)
	
	if tempC <= 0
		message = 'Freeze warning';
		isFreezing = true;
	elseif tempC <= tempWarn
		message = 'Freeze warning';
		isFreezing = false;
	else
		message = 'No warning';
		isFreezing = false;
	end
end
