      In MATLAB, the values true and 1 are exactly the same and can always be used interchangeably.
      🔗

    • True.

    • While true and 1 appear similar and behave similarly in many contexts, they are different data types. true is a logical value, while 1 is a numeric (double) value. You can see this difference using the whos command.

    (e) Basic Logical Operators.

    Evaluate the following logical expression in MATLAB:
    🔗
    (3 >= 2) & (3+4 == 6)
    What is the result of this expression?
    🔗
    • 0 (false)
    • Correct! Even though 3 >= 2 is true, the expression 3+4 == 6 is false (since \(3+4=7\)). For an AND operation to be true, both sides must be true.
    • 1 (true)
    • Incorrect. While 3 >= 2 is true, check the second part: is \(3+4\) really equal to \(6\text{?}\)
    🔗

      An AND operation (&) returns true if at least one of the conditions is true.

    (m) Short-Circuit Operators.

    When should you use && and || instead of & and |?
    🔗
    • When working with scalar logical values in conditional statements (like if)
    • Correct! The short-circuit operators && and || are designed for scalar logical values and are commonly used in conditional statements. They also provide short-circuit evaluation, which can prevent errors.
    • When performing element-wise operations on arrays
    • Incorrect. Use & and | for element-wise operations on arrays. The short-circuit operators && and || work only with scalar values.
    • They are completely interchangeable and can be used in any situation
    • Incorrect. While they behave similarly for scalar values, && and || do not work on arrays, and & and | do not provide short-circuit evaluation.
    • When you want the computation to run faster
    • Partially correct. Short-circuit operators can be faster because they skip unnecessary evaluations, but the main reason to use them is for scalar logical expressions and to prevent potential errors in conditionals.
