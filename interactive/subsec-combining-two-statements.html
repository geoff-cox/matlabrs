    Subsection Joining Logical Statements

    Subsubsection Combining Two Logical Statements

    Many questions involve multiple conditions. For example, to determine if a number is an even number greater than 100, then you need to check two things at once:
    • Is the number even?
      🔗
    • Is the number greater than 100?
      🔗
    Because both must be true, we join these statements with “and”. If either of these conditions could be true, then we would join them with “or”.
    🔗
    MATLAB joins logical statements with AND and OR using the operators & (AND) and | (OR).
    🔗
    The result of joining logical statements are exactly what you would expect from everyday language: AND is true only when both sides are true, while OR is true when at least one side is true.
    🔗
    % Quick checks
true  & true	% → true:  1 (logical)
true  & false	% → false: 0 (logical)
false & true	% → false: 0 (logical)
false & false	% → false: 0 (logical)

true  | true	% → true:  1 (logical)
true  | false	% → true:  1 (logical)
false | true	% → true:  1 (logical)
false | false	% → false: 0 (logical)
    Now try these operators in context.
    🔗
    P = 1;
Q = 10;
R = -4;

P <= R & P > Q	  % → false	& false: 0 (logical)
R < 0 & R < Q	  % → true	& true:  1 (logical)
Q == R | Q == P	  % → false	| false: 0 (logical)
P < Q | P < R	  % → true	| false: 1 (logical)

~(P < Q & P < R)  % → NOT (true & false): 1 (logical)
P > Q | P > R	  % → false | true:		  1 (logical)
    🔗

    Subsubsection Combining Many Logical Statements

    You can combine more than two logical statements, and you can mix ~, &, and | in the same expression. When you do, MATLAB evaluates operators in a fixed precedence order. Parentheses override everything, so you can always force the grouping you intend.
    🔗
    MATLAB evaluates logical operators in the following order: first ~, then &, then |.
    🔗
    Here are some equivalent rewrites that illustrate that precedence:
    • ~A & B is interpreted as (~A) & B.
      🔗
    • ~A | B is interpreted as (~A) | B.
      🔗
    • A & B | C is interpreted as (A & B) | C.
      🔗
    • A | B & C is interpreted as A | (B & C).
      🔗
    🔗
    When in doubt, use parentheses. They make your code clearer to readers and reduce errors caused by misinterpreting precedence.
    🔗

    📝: Short-Circuit Operators: && and ||.

    MATLAB also provides short-circuit logical operators: && (AND) and || (OR). These work only with scalar logical values (true/false), not arrays. When the left side of the expression already determines the outcome, MATLAB skips evaluating the right side.
    🔗
    Use && and || in conditional statements (like if-statements) where you need a single true/false answer. Use & and | when working with arrays of logical values.
    🔗
    x = 4;

% Scalar logic (typical in conditionals)
(x > 0) && (x < 10)

% Array logic (elementwise)
A = [-2 0 5 7];
(A > 0) & (A < 6)     % true where A is between 1 and 5
    Short-circuit evaluation can prevent errors. For example, checking if an array is non-empty before indexing:
    🔗
    % This prevents indexing errors when A is empty
if ~isempty(A) && A(1) < 0
	disp("First entry is negative.")
end
