Using the Command Window.

The basic pattern for using the Command Window is:
🔗
>> expression_or_command
Key rules:
  • Type a mathematical expression or command at the >> prompt and press Enter.
    🔗
  • If you do not assign the result to a variable, MATLAB stores it in the special variable ans.
    🔗
  • End a command with a semicolon ; to suppress output display; the result is still computed and stored.
    🔗
  • MATLAB includes built-in constants such as pi, and functions such as sin(x), exp(x), sqrt(x), and abs(x).
    🔗
🔗
Session management commands:
  • clear — removes all variables from the workspace.
    🔗
  • clc — clears the Command Window display (does not delete variables).
    🔗
  • format — controls how numerical output is displayed.
    🔗
