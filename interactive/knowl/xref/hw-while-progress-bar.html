Task 4.4.2.l. Progress Bar.

Write a function progressBar() that uses fprintf to display a text-based progress bar showing how much of a task is complete. The bar should be 20 characters wide, using # for completed portions and a space for the remainder, enclosed in square brackets. After the closing bracket, print the percentage complete.
🔗
Since 20 # represents 100%, you’ll need to scale the progress out of 20 and round it to the nearest integer to determine how many # characters to print. For example, if done is 2 and total is 8, then the progress is 25% and you will need 5 # characters.
🔗
Use a while-loop, fprintf, and round to code this. Don’t use a newline character, "\n", in any of your fprintf calls.
🔗
Note: to print a % character with fprintf, use "%%".
🔗
Inputs:
done
🔗
(1x1) double
🔗
amount of work completed
🔗
total
🔗
(1x1) double
🔗
total amount of work
🔗
Outputs:
None
🔗
display to command window with fprintf
🔗
Test Cases ⤵︎
🔗
progressBar(0, 10)
progressBar(11, 50)
progressBar(58, 100)
progressBar(17, 17)
Expected ⤵︎
🔗
[                    ]   0%
[####                ]  22%
[############        ]  58%
[####################] 100%
