    Subsection Nested Loops

    A nested loop is a loop inside another loop. Nested loops appear naturally when you need to work over a grid, a table, or the entries of a matrix. The outer loop controls one index (like the row), and the inner loop controls another (like the column).
    🔗

    Subsubsection Building a Matrix Entry-by-Entry

    The following example builds a multiplication table matrix, where M(i,j) = i*j. Preallocate first, then fill entries.
    🔗
    m = 5;
n = 6;

M = zeros(m,n);

for i = 1:m
		for j = 1:n
				M(i,j) = i*j;
		end
end

M
    🔗

    Subsubsection Efficiency and Alternatives

    Nested loops can be computationally expensive when arrays are large because the total number of iterations grows like (rows) times (columns). MATLAB often provides vectorized operations that are faster and shorter. Still, nested loops remain useful when the update rule is complicated or when you are implementing an algorithm step-by-step.
    🔗
    🔗

    Subsubsection Nested LoopsRepeating a Repeat

    Sometimes the task you need to repeat also contains repetition. That is when you use a nested loop: a loop inside another loop. The outer loop controls the “bigger” repetition, and for each outer iteration, the inner loop runs through its own full set of iterations.
    🔗
    A typical nested-loop skeleton looks like this:
    🔗
    for k = 1:6

    % Perform the "j" loop for each k
    for j = 1:3

        % Do something for each k and j

    end

end
    This example shows nested for-loops, but the same idea applies to while-loops. You can even mix a for-loop on the outside with a while-loop on the inside (or vice versa) when it fits the situation.
    🔗

    Example 1: Predicting Printed Output.

    The simplest way to understand nesting is to watch the order of execution. In the loop below, the inner loop runs completely for k = 1, then runs completely again for k = 2.
    🔗
    for k = 1:2
    for j = [2 5 1]
        fprintf('k = %g and j = %g \n', k, j)
    end
end
    This prints six lines total, because there are 2 outer iterations and 3 inner iterations per outer iteration: \(2 \times 3 = 6\text{.}\)
    🔗
    🔗

    Example 2: A Two-Index Computation Without Arrays.

    Your original demo used nested loops to process a table of values entry-by-entry. Since we are postponing arrays, we will keep the same core idea—two indices, two levels of repetition—but use a purely scalar computation.
    🔗
    In the code below, think of r and c as “row” and “column” counters that identify a position in a conceptual grid. For each pair (r,c), we compute a scalar value and print it.
    🔗
    for r = 1:4
    for c = 1:3

        % A scalar computation that depends on both indices
        value = r^2 - 2*c + 1;

        fprintf('(r,c) = (%g,%g), value = %g \n', r, c, value)

    end
end
    Even without storing results, this example demonstrates the main nested-loop habit: the inner loop runs through all c-values for a fixed r, then r advances and the process repeats.
    🔗
    🔗

    Example 3: Counting How Often a Condition Happens.

    Another classic nested-loop task is counting how many times something happens while scanning over a two-index space. When arrays are introduced, the “something” is often “this entry equals zero.” For now, we can practice the same skill by generating a scalar value from (r,c) and counting how often it equals zero.
    🔗
    The function below counts the number of index pairs (r,c) in an n_rows-by-n_cols grid for which a particular scalar expression evaluates to 0.
    🔗
    function count = zero_count_grid(n_rows, n_cols)

    count = 0;

    for r = 1:n_rows
        for c = 1:n_cols

            % A scalar "cell value" defined by r and c
            cell_value = r - c;

            if cell_value == 0
                count = count + 1;
            end

        end
    end

end
    Test it on a few sizes. For example, on a 4-by-3 grid, cell_value = r - c equals 0 exactly when r = c, so the count should be the number of matching pairs that fit in that rectangle.
    🔗
    count1 = zero_count_grid(4,3)
count2 = zero_count_grid(10,10)
    🔗

    Takeaways.

    • A nested loop is a loop inside a loop. The inner loop completes all of its iterations for each iteration of the outer loop.
      🔗
    • Nested loops naturally model processes indexed by two counters (like r and c).
      🔗
    • When arrays are introduced, nested loops become a direct way to process data stored in a grid-like structure. For now, you can still practice the same reasoning by computing scalar values from two indices.
