    1. Creating and Indexing Vectors.

    (a)

    Write a function firstAndLast that takes a vector v and returns its first and last elements as two separate outputs.
    🔗
    Inputs:
    v
    🔗
    (1xn) double
    🔗
    vector with at least one element
    🔗
    Outputs:
    first
    🔗
    (1x1) double
    🔗
    first element of v
    🔗
    last
    🔗
    (1x1) double
    🔗
    last element of v
    🔗
    Test Cases ⤵︎
    🔗
    [a, b] = firstAndLast([3, 7, 2, 9, 5])
[a, b] = firstAndLast([42])
[a, b] = firstAndLast(1:10)
    Expected ⤵︎
    🔗
    a = 3,  b = 5
a = 42, b = 42
a = 1,  b = 10
    🔗

    (b)

    Write a function swapEnds that takes a vector v and returns a new vector with the first and last elements swapped. All other elements should remain in place.
    🔗
    Inputs:
    v
    🔗
    (1xn) double
    🔗
    vector with at least two elements
    🔗
    Outputs:
    w
    🔗
    (1xn) double
    🔗
    vector with the first and last elements swapped
    🔗
    Test Cases ⤵︎
    🔗

    Expected ⤵︎
    🔗
    w = [5, 2, 3, 4, 1]
w = [20, 10]
w = [7, 7, 7, 7]
