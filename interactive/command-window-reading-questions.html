    1.

    (a)

    When you enter an expression in the Command Window without assigning it to a variable, how does MATLAB store the result?
    🔗
    • It stores the result in the special variable ans.
    • Correct. MATLAB always stores the last unassigned result in ans, which appears in the Workspace.
    • It permanently saves the result to a file.
    • Results are stored in memory (the workspace), not automatically saved to a file.
    • It discards the result immediately.
    • MATLAB always stores the result; unassigned results go into ans.
    • It replaces the entire contents of the workspace.
    • Only the value of ans is updated. Other variables in the workspace are not affected.
    🔗

    (b)

    Which command clears variables from memory without closing MATLAB?
    🔗
    • clear
    • Correct. clear removes all variables from the workspace without closing MATLAB or clearing the Command Window display.
    • clc
    • clc clears the Command Window display but does not remove variables from memory.
    • format
    • format controls how numbers are displayed, not memory management.
    • exit
    • exit closes MATLAB entirely. To clear just variables, use clear.
    🔗

    (c)

      Adding a semicolon at the end of a MATLAB command prevents the variable from being created.
      🔗

    • True.

    • Incorrect. A semicolon only suppresses the output display in the Command Window. The variable is still created and stored in the workspace.

    • False.

    • Incorrect. A semicolon only suppresses the output display in the Command Window. The variable is still created and stored in the workspace.

    2. Command Window Practice.

    Try these Command Window exercises. Predict the output before evaluating.
    🔗

    (a)

    What will MATLAB display after running:
    🔗
    3 * 4 + 2
    Solution.
    ans = 14. MATLAB follows standard order of operations: multiplication before addition. \(3 \times 4 = 12\text{,}\) then \(12 + 2 = 14\text{.}\)
    🔗
    🔗
    🔗

    (b)

    What will MATLAB display after running these two lines in sequence?
    🔗
    5 + 3
ans * 2
    Solution.
    The first line produces ans = 8. The second line uses ans (which is 8) and multiplies by 2, producing ans = 16.
    🔗

    What happens when you type an expression in the Command Window without assigning it to a variable?
    🔗
    • The result is stored in the variable ans and displayed.
    • Correct. MATLAB uses ans as a temporary storage for unassigned expressions, and displays the result.
    • The result is discarded.
    • The result is not discarded; it is stored in ans.
    • MATLAB displays an error because no variable was specified.
    • MATLAB does not require you to assign every result. Unassigned results go into ans.
    • The result is automatically saved to a file.
    • Results are stored in memory as ans, not automatically saved to a file.

    5.

    What is the difference between clear and clc?
    🔗
    • clear removes variables from the workspace; clc clears the Command Window display.
    • Correct. These are two different cleanup operations. clear affects memory; clc affects the screen.
    • clc removes variables from the workspace; clear clears the Command Window display.
    • These are reversed. clear removes variables; clc clears the display.
    • Both commands do the same thing: they remove all variables from memory.
    • They are not the same. clear removes variables; clc only clears the visual display.
    • Both commands clear the Command Window display without affecting variables.
    • Only clc clears the display. clear removes variables from memory.
    🔗

    6.

      The format command changes how numbers are displayed but does not change how they are stored internally.
      🔗

    • True.

    • Correct. format is purely a display setting. The full double-precision value is always stored; only the number of digits shown changes.

    • False.

    • Correct. format is purely a display setting. The full double-precision value is always stored; only the number of digits shown changes.

    7.

    A student runs the following commands:
    🔗
    3 + 4
ans + 10
    What is displayed after the second command?
    🔗
    • ans = 17
    • Correct. The first command sets ans = 7. The second adds 10 to ans, giving 17.
    • ans = 14
    • This would be \((3+4)+7\) = 14, but the second command uses ans (which is 7) and adds 10, giving 17.
    • ans = 10
    • This ignores the first command entirely. MATLAB uses the current value of ans (which is 7) and adds 10.
    • An error, because ans was not explicitly assigned.
    • MATLAB automatically updates ans after every unassigned expression, so this is valid.
    🔗

    8.

    Which of the following correctly describes what happens when you type pi in the Command Window?
    🔗
    • MATLAB displays the value of the built-in constant pi and stores it in ans.
    • Correct. pi is a built-in constant. Typing it returns its numeric value and stores it in ans.
    • MATLAB creates a new variable called pi with value 0.
    • MATLAB does not create a new variable. It reads the built-in constant and stores the result in ans.
    • MATLAB displays the letter “pi” as text.
    • MATLAB evaluates pi as a numeric constant, not as text.
    • MATLAB returns an error because pi is not defined.
    • pi is a built-in constant in MATLAB. No error occurs.
    🔗

    • A semicolon does not prevent variable creation. It only suppresses the display.
    • The variable result is created and result = 24 is displayed.
    • The semicolon suppresses the display. The variable is created but not shown.
    • MATLAB displays an error because of the missing output.
    • A semicolon is valid MATLAB syntax. No error is produced.

    • Correct. format long increases display precision to 15 significant digits, but the underlying stored value is unchanged.
    • Numbers are stored with more precision.
    • MATLAB always stores doubles at full precision. format only changes the display, not the stored value.
    • All variables are rounded to more decimal places.
    • No rounding occurs. format long only changes how many digits are shown on screen.
    • MATLAB switches to a different number type such as integers.
