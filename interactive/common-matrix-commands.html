    Section 6.7 Common Matrix Functions

    🗝️ Key Takeaways...

    By the end of this section, you will be able to ...
    🔗
    1. Apply various scientific functions to the values of a matrix,
      🔗
    2. Compute the maximum or minimum of the values in a matrix, and
      🔗
    3. Compute the sum or product of the values in a matrix.
      🔗
    🔗
    In this section, we will list some common built-in functions that apply to either each value of a matrix (element-wise) or on the rows or columns of the matrix (row/column-wise).
    🔗

    Common Scientific Functions.

    🔗
    MATLAB also contains a large library of functions you might find on a scienfic/graphing calculator. Most of the common functions (e.g. \(\sin, \cos, \log,\) etc.) require a single number input. However, MATLAB, has designed these common functions to take a matrix as an input. In particular, MATLAB applies these functions element-wise, as shown below for the \(\sin\) function.
    \(\sin\) \(\left( \left[ \begin{matrix} A_{11} \amp A_{12} \amp \dots \amp A_{1n} \\ A_{21} \amp A_{22} \amp \dots \amp A_{2n} \\ \vdots \amp \vdots \amp \ddots \amp \vdots \\ A_{m1} \amp A_{m2} \amp \dots \amp A_{mn} \\ \end{matrix} \right]\right) = \left[ \begin{matrix} \sin(A_{11}) \amp \sin(A_{12}) \amp \dots \amp \sin(A_{1n}) \\ \sin(A_{21}) \amp \sin(A_{22}) \amp \dots \amp \sin(A_{2n}) \\ \vdots \amp \vdots \amp \ddots \amp \vdots \\ \sin(A_{m1}) \amp \sin(A_{m2}) \amp \dots \amp \sin(A_{mn}) \\ \end{matrix} \right]\)
    🔗
    🔗

    👀 Quick Review 6.39. Trigonometric Functions.

    🔗
    Let A be an \(m \times n\) matrix variable containing values in radians.
    🔗
    Command
    🔗
    		 result = sin(A), result = cos(A), result = tan(A)
    result = csc(A), result = sec(A), result = cot(A)
    Output
    🔗
    result (\(m \times n\)) matrix containing the chosen trig function applied to each value in A.
    🔗
    Notes
    If A contains degree values instead of radians, use the functions:
    🔗
    result = sind(A), result = cosd(A), result = tand(A)
    result = cscd(A), result = secd(A), result = cotd(A)
    🔗
    🔗

    🌌 Example 6.40.

    🔗
    Let \(A\) and \(B\) be given by
    \begin{equation*} A = \left[ \begin{matrix} \pi \amp 0 \amp 2 \\ 2\pi \amp \pi/2 \amp 4 \\ \end{matrix}\right], \qquad B = \left[ \begin{matrix} 0 \amp 30 \amp 60 \amp 90 \\ \end{matrix}\right] \end{equation*}
    🔗
    where \(A\) contains radian values and \(B\) contains degree values.
    🔗
    Give the MATLAB command that
    1. defines, sin_A, as the matrix containing the \(\sin\) of all the values in A.
      🔗
    2. defines, cos_B, as the matrix containing the \(\cos\) of all the values in B.
      🔗
    Recall, the MATLAB constant for \(\pi\) is pi.
    🔗
    🔗
    Solution.
    Since the values in A are in radians and the values in B are in degrees, we use the commands 
    A = [pi 0 2;2*pi pi/2 4];
sin_A = sin(A)
B = [0 30 60 90];
cos_B = cosd(A)
    🔗
    Running these commands, gives the output 
    sin_A =

	 0.0000         0    0.9093
	-0.0000    1.0000   -0.7568

cos_B =

	0.9985    1.0000    0.9994
	0.9940    0.9996    0.9976
    🔗
    🔗
    🔗

    👀 Quick Review 6.41. exp,log, and sqrt functions.

    🔗
    Let A be an \(m \times n\) matrix variable.
    🔗
    Command
    🔗
    		 result = exp(A) (exponential function, \(e^x\)),
    Output
    🔗
    result (\(m \times n\)) matrix containing the exponent of each value in A.
    🔗
    Command
    🔗
    result = log(A) (natural logarithm function, \(\ln x\)),
    🔗
    Output
    🔗
    result (\(m \times n\)) matrix containing the natural log of each value in A.
    🔗
    Command
    🔗
    		 result = sqrt(A) (square root function, \(\sqrt{x}\)),
    Output
    🔗
    result (\(m \times n\)) matrix containing the square root of each value in A.
    🔗
    🔗
    🔗

    🌌 Example 6.42.

    🔗
    Let
    \begin{equation*} A = \left[ \begin{matrix} 9 \amp 0\\ 16 \amp 4\\ 25 \amp 1\\ \end{matrix}\right]. \end{equation*}
    🔗
    Give the command that computes the square root of all the values in A.
    🔗
    🔗
    Solution.
    Running the commands 
    A = [9 0;16 4;25 1];
sqrt(A)
    🔗
    gives the output 
    sqrt_A =

	3     0
	4     2
	5     1
    🔗
    🔗
    🔗
    🔗

    Row/Column-Wise Functions.

    🔗
    MATLAB also contains a huge library of functions that perform common programming tasks on a list of numbers. For example, we may want the find the sum or maximum value of this list. It is natural to think of a list as a row or column vector and MATLAB can easily sum a list of such values. However, MATLAB goes a bit further by allowing you to sum several lists at once. Let’s take a closer look at this idea.
    🔗
    A fundamental concept needed in many applications is to find the sum or product of a list of numbers.
    🔗

    👀 Quick Review 6.43. sum and prod functions (vector).

    🔗
    Let v be a row vector (\(m \times 1\)) or column vector (\(1 \times n\)).
    🔗
    Command
    🔗
    		 result = sum(v)
    Output
    🔗
    result is equal to the sum of all the elements in v.
    🔗
    Command
    🔗
    		 result = prod(v)
    Output
    🔗
    result isequal to the product of all the elements in v.
    🔗
    🔗
    🔗
    Another common task is to get the maximum or minimum from a list of values.
    🔗

    👀 Quick Review 6.44. min and max functions (vector).

    🔗
    Let v be a row vector (\(m \times 1\)) or column vector (\(1 \times n\)).
    🔗
    Command
    🔗
    		 result = min(v)
    Output
    🔗
    result is equal to the minimum of all the elements in v.
    🔗
    Command
    🔗
    		 result = max(v)
    Output
    🔗
    result is equal to the maximum of all the elements in v.
    🔗
    🔗
    🔗

    🌌 Example 6.45.

    🔗
    🔗
    Let
    \begin{equation*} v = \left[ \begin{matrix} 10 \\ 6 \\ -1 \\ \end{matrix}\right]. \end{equation*}
    🔗
    Give the command that
    1. defines sum_v as the sum of the values in v.
      🔗
    2. defines prod_v as the product of the values in v.
      🔗
    3. defines min_v as the minimum of the values in v.
      🔗
    4. defines max_v as the maximum of the values in v.
      🔗
    🔗
    🔗
    Solution.
    Running the commands 
    v = [10; 6; -1];
sum_v = sum(v)
prod_v = prod(v)
min_v = min(v)
max_v = max(v)
    🔗
    produces the output 
    sum_v = 15
prod_v = -60
min_v =	-1
max_v = 10
    🔗
    🔗
    🔗
    The above example shows how common functions apply to a vector, but what about a matrix? It turns out that MATLAB treats a matrix as a list of column vectors and applies the function to each column. The output is a row vector containing the result of the function applied to each column. Visually, if
    \begin{equation*} A = \left[ \begin{matrix} 9 \amp 1 \amp 7 \\ 5 \amp 2 \amp 1 \\ 9 \amp 3 \amp 0 \\ \end{matrix} \right] \end{equation*}
    then the sum(A) and max(A) would be computed, column-wise, like so,
    🔗
    This is the default behavior, but you can easily tell MATLAB to apply the function to the rows instead of the columns.
    🔗

    👀 Quick Review 6.46. sum and prod functions (matrix).

    🔗
    Let A be a matrix (\(m \times n\)).
    🔗
    Command
    🔗
    		 result = sum(A) or result = sum(A,1)
    Output
    🔗
    result is a \(1 \times n\) matrix (row vector) that contains the sum of the elements in each column of A.
    🔗
    Command
    🔗
    		 result = sum(A,2)
    Output
    🔗
    result is a \(m \times 1\) matrix (column vector) that contains the sum of the elements in each row of A.
    🔗
    Command
    🔗
    		 result = sum(sum(A))
    Output
    🔗
    result is a \(1 \times 1\) matrix (number) that contains the sum of all elements in A.
    🔗
    Command
    🔗
    		 result = prod(v) or result = prod(A,1)
    Output
    🔗
    result is a \(1 \times n\) matrix (row vector) that contains the product of the elements in each column of A.
    🔗
    Command
    🔗
    		 result = prod(A,2)
    Output
    🔗
    result is a \(m \times 1\) matrix (column vector) that contains the product of the elements in each row of A.
    🔗
    Command
    🔗
    		 result = prod(prod(A))
    Output
    🔗
    result is a \(1 \times 1\) matrix (number) that contains the product of all elements in A.
    🔗
    🔗

    🌌 Example 6.47.

    🔗
    🔗
    Let
    \begin{equation*} A = \left[ \begin{matrix} 1 \amp 2 \amp 3 \amp 4 \\ 5 \amp 6 \amp 7 \amp 8 \end{matrix}\right]. \end{equation*}
    🔗
    Give the command that
    1. defines c_sum as the sum of the values in each column of A.
      🔗
    2. defines r_sum as the sum of the values in each row of A.
      🔗
    3. defines t_sum as the sum of all the values in A.
      🔗
    🔗
    🔗
    Solution.
    Define A first, of course 
    >> A = [1 2 3 4;5 6 7 8];
    🔗
    For the column sums, use
    Command: 
    >> c_sum = sum(A)  % or
>> c_sum = sum(A,1)
    🔗
    Output: 
    c_sum =
	6     8    10    12
    🔗
    For the row sums, use
    Command: 
    >> r_sum = sum(A,2)
    🔗
    Output: 
    r_sum =
	10
	26
    🔗
    Finally, we have a few options for the sum of all the elements. We can use the
    Command: 
    >> t_sum = sum(c_sum)  % or
>> t_sum = sum(r_sum)  % or
>> t_sum = sum(sum(A))
    🔗
    Output: 
    t_sum =
	36
    🔗
    🔗
    🔗
    🔗

    🔗
    🔗
    Let
    \begin{equation*} A = \left[ \begin{matrix} 1 \amp 0 \amp 3\\ 8 \amp -1 \amp 3\\ 1 \amp 7 \amp 3 \\ 5 \amp 16 \amp 8 \end{matrix}\right]. \end{equation*}

    Give the command that

    🔗
    🔗

    🔗

    r_min =

	0
	-1
	1
	5

    Finally, we have a few options for the min of all the elements. We can use the
    Command: 
    >> t_min = min(c_min)  % or
>> t_min = min(r_min)  % or
>> t_min = min(min(A))
    🔗
    Output: 
    t_min =
	-1
