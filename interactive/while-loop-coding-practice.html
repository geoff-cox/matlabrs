    2. Converting for loops to while loops.

    (a)

    Every for-loop can be rewritten as a while-loop. The pattern is:
    🔗
    for-loop ⤵︎
    🔗
    for k = start:step:stop
	loop_body
end
    Equivalent while-loop ⤵︎
    🔗
    k = start;
while k <= stop
	loop_body
	k = k + step;
end
    For each for-loop below, rewrite it as an equivalent while-loop. Replace each ? with the appropriate code.
    🔗
    total = 0;
for k = 1:5
	total = total + k;
end
fprintf('total = %i\n', total)
    When done, evaluate and confirm it prints total = 15.
    🔗
    Solution.
    total = 0;
k = 1;
while k <= 5
	total = total + k;
	k = k + 1;
end
fprintf('total = %i\n', total);
    🔗
    🔗

    (b)

    product = 1;
for k = 2:2:10
	product = product * k;
end
fprintf('product = %i\n', product)
    When done, evaluate and confirm it prints product = 3840.
    🔗
    Solution.
    product = 1;
k = 2;
while k <= 10
	product = product * k;
	k = k + 2;
end
fprintf('product = %i\n', product);
    🔗
    🔗

    (c)

    for n = 10:-3:1
	fprintf('%d, ', n)
end
fprintf('\n')
    When done, evaluate and confirm it prints 10, 7, 4, 1,.
    🔗
    Solution.
    n = 10;
while n >= 1
	fprintf('%d, ', n);
	n = n - 3;
end
fprintf('\n');

    (b) Approximating Pi.

    In the previous section, you approximated \(\pi\) using the Leibniz formula:
    \begin{equation*} \frac{\pi}{4} = 1 - \frac{1}{3} + \frac{1}{5} - \frac{1}{7} + \frac{1}{9} - \cdots \end{equation*}
    with a for-loop:
    🔗
    N = 10;  total = 0;
for k = 1:N
	total = total + (-1)^(k+1) * 1/(2*k - 1);
end
approx = total * 4;
fprintf('          pi ≈ %10.8g\n', pi);
fprintf('approx of pi ≈ %10.8g\n', approx);
    Work through the tasks below to convert this to a while-loop.
    🔗
    Now update your while-loop so that instead of stopping after a fixed number of terms, it keeps adding terms until the approximation is within 0.001 of pi. Track the number of terms needed in N.
    🔗
    Solution.
    N = 10;  total = 0;
%─── TYPE YOUR CODE HERE ───%
distFromPi = Inf;
while distFromPi > 0.001
	N = N + 1;
	total = total + (-1)^(N+1) * 1/(2*N - 1);
	distFromPi = abs(4 * total - pi);
end
%───────────────────────────%
approx = total * 4;
fprintf('          pi ≈ %10.8g\n', pi);
fprintf('approx of pi ≈ %10.8g\n', approx);
fprintf('terms needed = %i\n', N);

    (c) Approximating Pi.

    Introduce a variable called tol to represent the “closeness” tolerance. Experiment with the different tolerances: 0.0001 and 0.00001. How does the number of terms change?
    🔗
    Notice that each extra digit of accuracy requires roughly 10 times as many terms. This series converges very slowly.
    🔗
    Solution.

tol = 0.001;
distFromPi = Inf;
while distFromPi > tol
	N = N + 1;
	total = total + (-1)^(N+1) * 1/(2*N - 1);
	distFromPi = abs(4 * total - pi);
end
%───────────────────────────%
approx = total * 4;
fprintf('          pi ≈ %10.8g\n', pi);
fprintf('approx of pi ≈ %10.8g\n', approx);

fprintf('terms needed = %i\n', N);

    (d)

    Write a function doubleUntil(x, N) that uses a while-loop to determine how many times x must be doubled before it exceeds N. Return the number of doublings and the final value.
    🔗
    For example, if \(x = 3\) and \(N = 20\text{,}\) then repeatedly doubling \(3\) gives:
    \begin{equation*} 3 \overset{1}{\to} 6 \overset{2}{\to} 12 \overset{3}{\to} 24\text{.} \end{equation*}
    So, \(3\) was doubled \(3\) times and the final value was \(24\text{.}\)
    🔗
    Inputs:
    x
    🔗
    (1x1) double
    🔗
    positive starting value
    🔗
    N
    🔗
    (1x1) double
    🔗
    threshold to exceed
    🔗
    Outputs:
    count
    🔗
    (1x1) double
    🔗
    number of doublings performed
    🔗
    final
    🔗
    (1x1) double
    🔗
    final value after the last doubling
    🔗
    Test Cases ⤵︎
    🔗
    [c, v] = doubleUntil(5, 76)
[c, v] = doubleUntil(13.2, 52.7)
[c, v] = doubleUntil(3, 2)
    Expected ⤵︎
    🔗
    c = 4   v = 80
c = 2   v = 52.8
c = 0   v = 3
    Solution.
    function [count, final] = doubleUntil(x, N)
	count = 0;
	final = x;

	while final <= N
		final = 2 * final;
		count = count + 1;
	end
end

    (f)

    Write a function yearsToDouble(rate) that determines how many years it takes for an investment to double at a given annual interest rate. Each year, the balance grows by balance = balance * (1 + rate). Assume an initial balance of $1.
    🔗
    Inputs:
    rate
    🔗
    (1x1) double
    🔗
    annual interest rate as a decimal (e.g., 0.05 for 5%)
    🔗
    Outputs:
    years
    🔗
    (1x1) double
    🔗
    number of years to at least double the investment
    🔗
    Test Cases ⤵︎
    🔗
    years = yearsToDouble(0.05)

years = yearsToDouble(0.01)
    Expected ⤵︎
    🔗
    years = 15
years = 8
years = 70
    Solution.
    function years = yearsToDouble(rate)
	balance = 1;
	goal = 2;
	years = 0;

	while balance < goal
		balance = balance * (1 + rate);
		years = years + 1;
	end
end

    (g)

    Write a function called makeChange that breaks a number of cents into quarters, dimes, nickels, and pennies using the greedy algorithm.
    🔗
    Use a separate while-loop for each coin type. Start with quarters, then dimes, then nickels, and finally pennies. Return the number of each coin used and totalCoins, the total number of coins in the final breakdown.
    🔗
    For U.S. coins, this greedy process gives the fewest coins possible.
    🔗
    Inputs:
    amount
    🔗
    (1x1) double
    🔗
    nonnegative integer
    🔗
    Outputs:
    q
    🔗
    (1x1) double
    🔗
    number of quarters used
    🔗
    d
    🔗
    (1x1) double
    🔗
    number of dimes used
    🔗
    n
    🔗
    (1x1) double
    🔗
    number of nickels used
    🔗
    p
    🔗
    (1x1) double
    🔗
    number of pennies used
    🔗
    change
    🔗
    (1x1) double
    🔗
    total number of coins used
    🔗
    Test Cases ⤵︎
    🔗
    [q, d, n, p, tot] = makeChange(99)
[q, d, n, p, tot] = makeChange(41)
[q, d, n, p, tot] = makeChange(30)
    Expected ⤵︎
    🔗
    q=3, d=2, n=0, p=4, tot=9
q=1, d=1, n=1, p=1, tot=4
q=1, d=0, n=1, p=0, tot=2
    Solution.
    function [quarters, dimes, nickels, pennies, totalCoins] = makeChange(amount)
	quarters = 0;
	dimes = 0;
	nickels = 0;
	pennies = 0;
	remainder = amount;

	while remainder >= 25
		remainder = remainder - 25;
		quarters = quarters + 1;
	end

	while remainder >= 10
		remainder = remainder - 10;
		dimes = dimes + 1;
	end

	while remainder >= 5
		remainder = remainder - 5;
		nickels = nickels + 1;
	end

	while remainder >= 1
		remainder = remainder - 1;
		pennies = pennies + 1;
	end

	totalCoins = quarters + dimes + nickels + pennies;
end
