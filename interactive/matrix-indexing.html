    Section 6.5 Accessing a Single Value

    🗝️ Key Takeaways...

    By the end of this section, you will be able to ...
    🔗
    1. Explain the difference between an index and value of a matrix.
      🔗
    2. Explain the difference between row/column indexing and absolute indexing.
      🔗
    3. Use matrix indexing to access a single value from a matrix.
      🔗
    🔗

    📝
    The act of "accessing values" in a matrix is also called "referencing" a matrix.
    🔗
    In this section, we look at ways to access values in a matrix using two different types of indexing.
    🔗

    Indices & Values.

    🔗
    All matrices contain values. Sometimes it makes sense to list the values in a straight line (i.e. with a vector) and other times it makes sense to list them in a rectangular grid (i.e. with a matrix). Either way, you need some way to get to these values. The location of these values is called the index. In MATLAB, an index must be a counting number (i.e. \(1, 2, 3, ...\)).
    🔗

    📝
    To give an analogy, suppose there is a line of four students and you say "The third student in line is Troy". Here, "Troy" would be the specified value and "third" (or 3) would be the index of this value.
    🔗
    For example, consider the following vector, \({\bf v}\text{:}\)
    \begin{equation*} {\bf v} = [7.1, -4.2, 1.1], \qquad \end{equation*}
    We can summarize the values and indices of \({\bf v}\) as follows:
    • The 1st value is \(7.1\) and it has an index of 1.
      🔗
    • The 2nd value is \(-4.2\) and it has an index of 2.
      🔗
    • The 3rd value is \(1.1\) and it has an index of 3.
      🔗
    🔗
    For matrices, the idea of index needs some adjustment. To see this, consider the following matrix, \(A\text{:}\)
    \begin{equation*} A = \left[ \begin{matrix} 3 \amp 4\\ 7 \amp 8 \end{matrix} \right]. \end{equation*}
    Since the values are listed in a rectangular grid, it is not so clear which value is the third value since you cannot just count them left to right as you could with \({\bf v}\text{.}\)
    🔗
    The next few sections aim to clarify this idea.
    🔗
    🔗

    Row/Column Indexing.

    🔗
    The most common way to locate a value in a matrix is to specify the row and column that the value is in. Remember, rows are counted from top to bottom and columns are counted from left to right, as shown here:
    columns
    \(\begin{matrix} 1 \amp 2 \amp 3 \amp 4\\ \downarrow \amp \downarrow \amp \downarrow \amp \downarrow \end{matrix}\)
    rows \(\begin{matrix} 1 \rightarrow\\ 2 \rightarrow\\ 3 \rightarrow \end{matrix}\) \(\left[ \begin{matrix} 5 \amp 0 \amp 6 \amp 3\\ 8 \amp 1 \amp 3 \amp 0\\ 2 \amp 9 \amp 7 \amp 4 \end{matrix} \right].\)
    🔗
    For example, the value, \(6\text{,}\) is in row \(1\) and column \(3\text{.}\)
    🔗

    👀 Quick Review 6.28. Row/Column Indexing.

    🔗
    🔗
    To access the value in row \(\texttt{i}\) and column \(\texttt{j}\) of matrix \(\texttt{A}\) , use the command:
    🔗
    					A(i,j)

    📝
    Important:
    • the row and column index must be separated by a comma, and
      🔗
    • rows are indexed first.
      🔗
    🔗
    Visually, the command, \(\texttt{A(i,j)}\,\,\) , will give you the value located at \(\boxed{*}\) .
    🔗
    \(\begin{matrix} \amp \amp \quad\texttt{j} \amp \\ \amp \amp \quad\downarrow \amp \end{matrix}\)
    \(\begin{matrix} \\ \\ \texttt{i} \rightarrow \end{matrix}\) \(\left[ \begin{matrix} \amp \amp \vdots \amp \\ \amp \amp \vdots \amp \\ \dots \amp \dots \amp \boxed{*} \amp \dots \\ \amp \amp \vdots \amp \end{matrix} \right]\)
    🔗

    🌌 Example 6.29.

    🔗
    Consider the matrix
    \begin{equation*} \left[ \begin{matrix} 5 \amp 0 \amp \boxed{6} \amp 3\\ 8 \amp 1 \amp 3 \amp 0\\ 2 \amp 9 \amp 7 \amp 4 \end{matrix} \right]. \end{equation*}
    Give the MATLAB commands that
    1. defines the variable, A, as this matrix above, and
      🔗
    2. defines the variable, x, as the boxed value in A. Get the value from the variable A.
      🔗
    🔗
    In the box, below, replace the ’?’ with the appropriate commands.
    🔗
    🔗
    Solution.
    Defining A should be a review. As for x, notice that boxed value is in row 1 and column 3 of A, so you should use the commands: 
    >> A = [5 0 6 3;8 1 3 0;2 9 7 4]
>> x = A(1,3)
    🔗
    and the output you should receive is 
    A =

5 0 6 3
8 1 3 0
2 9 7 4

x = 6
    🔗
    🔗
    🔗
    🔗

    Absolute Indexing.

    🔗
    MATLAB provides another way to locate a value in a matrix using just one index called the absolute index. This method locates the value by counting downward through each column from left to right until the value is found.
    🔗
    For example, suppose we wanted to the absolute index to access \(3\) (3rd column) in the following matrix:
    \begin{equation*} \left[ \begin{matrix} 5 \amp 0 \amp 6\\ 8 \amp 1 \amp \boxed{3}\\ 2 \amp 9 \amp 7 \end{matrix} \right]. \end{equation*}
    🔗
    Starting with the top-left value, count downward until you reach the bottom, then count down the next column, and continue this way until all the values have been counted.
    🔗
    To clarify, we’ve added subscripts to the values to illustrate the counting order:
    \begin{equation*} \left[ \begin{matrix} 5_\texttt{1} \amp 0_\texttt{4} \amp 6_\texttt{7}\\ 8_\texttt{2} \amp 1_\texttt{5} \amp \boxed{3}_\texttt{8}\\ 2_\texttt{3} \amp 9_\texttt{6} \amp 7_\texttt{9} \end{matrix} \right]. \end{equation*}
    🔗
    Counting this way, we see that the value \(3\) has an absolute index of 8.
    🔗

    👀 Quick Review 6.30. Absolute Indexing.

    🔗
    🔗
    To access the value with absolute index \(\texttt{i}\) of matrix \(\texttt{A}\) , use the command:
    🔗
    					A(i)
    Visually, the command, \(\texttt{A(i)}\,\,\) , will give you the value located at \(\boxed{*}\) .
    🔗
    \begin{equation*} \left[ \begin{matrix} \amp \amp \vdots \quad \amp \\ \amp \amp \vdots \quad \amp \\ \dots \amp \dots \amp \boxed{*}_\texttt{ i} \amp \dots \\ \amp \amp \vdots \quad \amp \end{matrix} \right] \end{equation*}
    where the subscript indicates the absolute index using the counting pattern:
    Starting with top-left value, count downward through each column until the last value is counted.
    🔗
    🔗

    🌌 Example 6.31.

    🔗
    Consider the matrix
    \begin{equation*} \left[ \begin{matrix} 1 \amp 2 \amp 3 \amp 4\\ 5 \amp 6 \amp \boxed{7} \amp 8\\ \end{matrix} \right]. \end{equation*}
    Give the MATLAB commands that
    1. defines the variable, x_rc, as the boxed value in A using row/column indexing.
      🔗
    2. defines the variable, x_ab, as the boxed value in A using absolute indexing.
      🔗
    🔗
    In the box, below, replace the ’?’ with the appropriate commands.
    🔗
    🔗
    Solution.
    Note that the boxed value is in row 2 and column 3 of A, so to access 7 using row/column indexing, the command is 
    >> x_rc = A(2,3)
    🔗
    Counting down each column, you get
    \begin{equation*} \left[ \begin{matrix} 1_\texttt{1} \amp 2_\texttt{3} \amp 3_\texttt{5} \amp 4_\texttt{7}\\ 5_\texttt{2} \amp 6_\texttt{4} \amp \boxed{7}_\texttt{6} \amp 8_\texttt{8}\\ \end{matrix} \right]. \end{equation*}
    🔗
    So to access 7 using the absolute index, the command is 
    >> x_ab = A(6)
    🔗
    Running all three commands, 
    A = [1 2 3 4; 5 6 7 8];
x_rc = A(2,3)
x_ab = A(6)
    🔗
    gives the output 
    x_rc = 7
x_ab = 7
    🔗
    Recall, the matrix, A, does not display in the output since we ended the first line with a semicolon.
    🔗
    🔗
    🔗
    🔗
    For completeness, in the last example, we can list out all the values of, A, in a row/column index grid:
    🔗
    A(1,1) = 1  A(1,2) = 2	A(1,3) = 3	A(1,4) = 4
A(2,1) = 5  A(2,2) = 6	A(2,3) = 7	A(2,4) = 8
    or, an absolute index grid:
    🔗
    A(1) = 1	A(3) = 2	A(5) = 3	A(7) = 4
A(2) = 5	A(4) = 6	A(6) = 7	A(8) = 8
