    The examples below emphasize two goals: translating English conditions into logical statements, and writing conditions that are readable.
    🔗

    1. Example 1: Simple if-gate.

    Complete the following tasks.
    🔗

    (a)

    Write a code block that defines x as 6 and sets y according to the following rule:
    • if x is less than or equal to 9, set y to 1, otherwise set y to 4.
      🔗
    🔗
    Solution 1.
    x = 6;

if x <= 9
	y = 1;
else
	y = 4;
end
    🔗
    Solution 2. (with commentary)
    x = 6;

if x <= 9
	fprintf('x = %d ≤ 9 is true\n', x);
	y = 1;
else
	fprintf('x = %d ≤ 9 is false\n', x);
	y = 4;
end

fprintf('so we set y to %d\n', y);
    🔗
    🔗

    (b)

    Change x to 16 and rerun your code block.
    🔗
    Solution.
    Just change the value of x to 16 in the previous code block.
    🔗
    🔗
    🔗

    (c)

    Now, suppose we define a variable x as a random integer between -5 and 15:
    🔗
    x = randi([-5, 15]);
    Rerun your code block multiple times to see how the value of y changes based on the random value of x.
    🔗
    Solution.
    Just change the value of x to randi([-5, 15]) in the previous code block.
    🔗
    🔗
    🔗

    (d)

    Write a code block that sets w according to the following rules:
    • if x is equal to 9, set w to 1
      🔗
    • if x is between (but not equal to) -4 and 0, set w to 2
      🔗
    • if x is not less than 3 or greater than 9, set w to 3
      🔗
    • if none of the above are true, set w to 4
      🔗
    🔗
    Solution 1.
    x = randi([-5, 15]);

if x == 9
	w = 1;
elseif x > -4 && x < 0
	w = 2;
elseif ~(x <= 3) || x > 9
	w = 3;
else
	w = 4;
end
    🔗
    Solution 2. (with commentary)
    x = randi([-5, 15]);
fprintf('x = %d\n', x);

if x == 9
	fprintf('x == 9 is true\n');
	w = 1;
elseif x > -4 && x < 0
	fprintf('-4 < x < 0 is true\n');
	w = 2;
elseif ~(x <= 3) || x > 9
	fprintf('x is not less than or equal to 3 or greater than 9 is true\n');
	w = 3;
else
	fprintf('none of the above conditions are true\n');
	w = 4;
end

fprintf('so we set w to %d\n', w);
    🔗
    🔗
    🔗

    2. if-else.

    Suppose num is a 1 x 1 double. Write a code block that increases num by 5 if it is greater than 10 and decreases it by 5 otherwise.
    🔗
    Solution 1.
    num = 68;
if num > 10
	num = num + 5;
else
	num = num - 5;
end
    🔗
    Solution 2. With Commentary
    num = 68;
fprintf("Since num = " + num + ", we ")
if num > 10
	num = num + 5;
	fprintf("add 5 to get num = " + num + "\n")
else
	num = num - 5;
	fprintf("subtract 5 to get num = " + num + "\n")
end
    🔗
    🔗

    3. Optional else.

    Suppose num is a 1 x 1 double. Write a code block that increases num by 5 if it is greater than 10 and decreases it by 5 otherwise.
    🔗
    Suppose x contains a numeric value. Write a script that increases x by 5 if it is greater than 10, decreases x by 5 if it is less than 10, and does nothing if x is zero.
    🔗
    Solution.
    If x = 0, the below script runs the commands x = x - 5 and disp(x), outputting -5. However, if x = 10, only the disp(x) command is run, producing an output of 10.
    🔗
    if x > 10
	x = x + 5;
elseif x < 10
	x = x - 5;
end
disp(x)
    🔗

    4. Case Study: Solving the Quadratic Equation in MATLAB.

    A classic programming task is turning a familiar mathematical procedure into a reliable piece of code. The quadratic equation is a great example because it combines algebra, branching logic, and careful handling of special cases.
    🔗
    Consider the quadratic polynomial \(a x^2 + b x + c\text{.}\) Its roots satisfy
    \begin{equation*} x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}. \end{equation*}
    The expression \(D = b^2 - 4ac\) is called the discriminant, and its sign determines the type of roots.
    🔗

    (a) The Discriminant and Root Types.

    There are three common cases: if \(D > 0\) there are two distinct real roots, if \(D = 0\) there is one repeated real root, and if \(D < 0\) the roots are complex conjugates.
    🔗
    a = 1; b = -3; c = 2;        % (x-1)(x-2) = 0

D = b^2 - 4*a*c;

x1 = (-b + sqrt(D)) / (2*a);
x2 = (-b - sqrt(D)) / (2*a);
    MATLAB’s sqrt can produce complex results automatically when \(D < 0\text{,}\) so the computation above still works. But it is often useful to detect the case and present results clearly.
    🔗
    🔗

    (b) Packaging the Computation as a Function.

    A function is the natural way to turn this idea into reusable code. We also add input checks to catch the invalid case \(a = 0\text{,}\) which would not be a quadratic.
    🔗
    function [r1, r2] = quadraticRoots(a,b,c)
%QUADRATICROOTS Return the roots of a*x^2 + b*x + c.
%
%   r1, r2 are the two roots (possibly equal or complex).

		if a == 0
				error("Input a must be nonzero for a quadratic polynomial.");
		end

		D = b^2 - 4*a*c;
		r1 = (-b + sqrt(D)) / (2*a);
		r2 = (-b - sqrt(D)) / (2*a);
end
    A function like this becomes more valuable when paired with clear documentation and predictable output format. In practice, you might also return the discriminant or a label indicating the root type.
    🔗
    🔗

    (c) A Numerical Note.

    For some coefficient values, the quadratic formula can suffer from roundoff error. This usually appears when \(b^2\) is much larger than \(4ac\text{,}\) causing subtractive cancellation. For introductory programming, the standard formula is perfectly acceptable, but it is good to know that numerical stability can matter even in “simple” algebra.
    🔗
    🔗
    🔗

    5. Making Decisions with if Statements.

    An if statement lets your program choose what to do based on a logical condition. This is the core mechanism behind “decision-making” in code: the program tests a condition and follows the branch that matches the result.
    🔗

    (a) Basic if Syntax.

    The simplest form has one condition and one block of code. If the condition is true, MATLAB executes the block. Otherwise, MATLAB skips it.
    🔗
    x = -2;

if x < 0
		disp("x is negative");
end
    The condition must evaluate to a single logical value. If you accidentally supply a logical array, MATLAB will error in modern versions. In those cases you typically want any or all.
    🔗
    🔗

    (b) Multiple Branches with elseif and else.

    Use elseif to test additional conditions, and else as a catch-all when none match. MATLAB checks conditions in order and takes the first branch that is true.
    🔗
    score = 83;

if score >= 90
		letter = "A";
elseif score >= 80
		letter = "B";
elseif score >= 70
		letter = "C";
elseif score >= 60
		letter = "D";
else
		letter = "F";
end

disp("Letter grade: " + letter)
    🔗

    (c) Using Logical Operators in Conditions.

    Many conditions combine multiple requirements. For scalar logic, prefer && and ||.
    🔗
    x = 4;

if (x > 0) && (x < 10)
		disp("x is between 0 and 10");
end
    🔗

    (d) Common Pitfalls and Best Practices.

    Two habits prevent a lot of bugs: first, make your conditions explicit and readable; second, test edge cases (like zeros, empty arrays, or unexpected input types).
    🔗
    For text comparisons, use functions like strcmp rather than == (especially when working with character arrays).
    🔗
    reply = "yes";

if strcmpi(reply, "yes")
		disp("Continuing...");
else
		disp("Stopping...");
end
    Short-Circuit Operators: && and ||.
    MATLAB also provides short-circuit logical operators: && (AND) and || (OR). These work only with scalar logical values (true/false), not arrays. When the left side of the expression already determines the outcome, MATLAB skips evaluating the right side.
    🔗
    x = 4;

% Scalar logic (typical in conditionals)
(x > 0) && (x < 10)
