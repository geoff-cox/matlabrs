    Subsection Two-Way Decisions with if-elseif

    When you have more than one possibility, you can add an elseif branch. MATLAB checks the first condition; if it is false, MATLAB checks the next one.
    🔗
    if x < 7
    y = 4;
elseif x >= y
    y = -3;
end
    Try running the code above with different starting values, such as: x = 9; y = 0;, x = 2; y = 0;, x = 6; y = 0;, and x = 7; y = 9;. Each pair forces MATLAB to take (or skip) a different branch, and that is the fastest way to build intuition.
