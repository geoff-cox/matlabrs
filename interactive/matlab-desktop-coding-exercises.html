    Exercises 1.5 💻 Coding Exercises

    Foundational.

    1. Explore Desktop Panels.

    These exercises guide you through interacting with each major panel of the MATLAB Desktop.
    🔗

    (a)

    Open MATLAB and identify the four main panels: Files, Command Window, Workspace, and Editor. In the Command Window, type the following and press Enter:
    🔗
    x = 10
    Verify that x appears in the Workspace panel with value 10.
    🔗
    🔗

    (b)

    In the Command Window, type clear and press Enter. What happens to the Workspace panel?
    🔗
    🔗

    (c)

    Open the Editor panel (go to “Home” tab, click “New Script”). Type the following in the Editor, save it as myFirstScript.m, and run it:
    🔗
    a = 3;
b = 4;
c = sqrt(a^2 + b^2)
    Confirm that c appears in the Workspace with the correct value and that the output is shown in the Command Window.
    🔗
    🔗
    🔗

    Variables.

    4. Volume & Surface Area of a Cylinder.

    Use the MATLAB command window to assign values for the radius and height of a cylinder, then compute its volume and surface area.
    🔗
    The volume and surface area of a cylinder is given by:
    \begin{equation*} V = \pi r^2 h, \qquad S = 2\pi r h + 2\pi r^2 \end{equation*}
    Use pi for \(\pi\) and use descriptive variable names.
    🔗
    Test your work with \(r = 1.2\) and \(h = 3.5\text{.}\)
    🔗
    🔗
    🔗

    5. Speed, Distance, and Time.

    Write a MATLAB script that stores a car’s speed and travel time in variables, then computes the distance traveled using \(d = s \cdot t\text{.}\)
    🔗
    Inputs:
    speed
    🔗
    (1x1) double
    🔗
    speed in miles per hour
    🔗
    time
    🔗
    (1x1) double
    🔗
    travel time in hours
    🔗
    Outputs:
    distance
    🔗
    (1x1) double
    🔗
    distance traveled in miles
    🔗
    Test with speed = 60 and time = 2.5; the result should be distance = 150.
    🔗
    🔗

    6. Celsius to Fahrenheit.

    Convert a temperature from Celsius to Fahrenheit using the formula \(F = \tfrac{9}{5}C + 32\text{.}\)
    🔗
    Inputs:
    tempC
    🔗
    (1x1) double
    🔗
    temperature in degrees Celsius
    🔗
    Outputs:
    tempF
    🔗
    (1x1) double
    🔗
    temperature in degrees Fahrenheit
    🔗
    Test with tempC = 100; the result should be tempF = 212.
    🔗
    🔗

    7. Compound Interest.

    Compute the balance after compounding for \(n\) years using \(A = P(1 + r)^n\text{,}\) where \(P\) is the principal, \(r\) is the annual interest rate, and \(n\) is the number of years.
    🔗
    Inputs:
    principal
    🔗
    (1x1) double
    🔗
    initial deposit in dollars
    🔗
    rate
    🔗
    (1x1) double
    🔗
    annual interest rate (e.g., 0.05 for 5%)
    🔗
    years
    🔗
    (1x1) double
    🔗
    number of years
    🔗
    Outputs:
    balance
    🔗
    (1x1) double
    🔗
    account balance after the given years
    🔗
    Test with principal = 1000, rate = 0.05, years = 3; the result should be approximately balance = 1157.625.
    🔗
    🔗

    8. Area and Perimeter of a Rectangle.

    Given the length and width of a rectangle, compute both its area and perimeter using descriptively named variables.
    🔗
    Inputs:
    rectLen
    🔗
    (1x1) double
    🔗
    length of the rectangle
    🔗
    rectWid
    🔗
    (1x1) double
    🔗
    width of the rectangle
    🔗
    Outputs:
    rectArea
    🔗
    (1x1) double
    🔗
    area of the rectangle
    🔗
    rectPerim
    🔗
    (1x1) double
    🔗
    perimeter of the rectangle
    🔗
    Test with rectLen = 5 and rectWid = 3; results should be rectArea = 15 and rectPerim = 16.
    🔗
    🔗

    9. Kinetic Energy.

    Compute the kinetic energy of a moving object using \(KE = \tfrac{1}{2}mv^2\text{.}\)
    🔗
    Inputs:
    mass
    🔗
    (1x1) double
    🔗
    mass of the object in kilograms
    🔗
    velocity
    🔗
    (1x1) double
    🔗
    speed of the object in meters per second
    🔗
    Outputs:
    kineticEnergy
    🔗
    (1x1) double
    🔗
    kinetic energy in joules
    🔗
    Test with mass = 2 and velocity = 3; the result should be kineticEnergy = 9.
