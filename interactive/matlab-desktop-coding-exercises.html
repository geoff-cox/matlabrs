    Exercises Coding Exercises

    Foundational.

    1. Explore Desktop Panels.

    These exercises guide you through interacting with each major panel of the MATLAB Desktop.
    🔗
    (a)
    Open MATLAB and identify the four main panels: Files, Command Window, Workspace, and Editor. In the Command Window, type the following and press Enter:
    🔗
    x = 10
    Verify that x appears in the Workspace panel with value 10.
    🔗
    Solution.
    After typing x = 10 and pressing Enter, the Command Window shows x = 10 and the Workspace panel updates to list x with value 10.
    🔗
    🔗
    🔗
    (b)
    In the Command Window, type clear and press Enter. What happens to the Workspace panel?
    🔗
    Solution.
    The Workspace panel becomes empty. The clear command removes all variables from memory.
    🔗
    🔗
    🔗
    (c)
    Open the Editor panel (go to “Home” tab, click “New Script”). Type the following in the Editor, save it as myFirstScript.m, and run it:
    🔗
    a = 3;
b = 4;
c = sqrt(a^2 + b^2)
    Confirm that c appears in the Workspace with the correct value and that the output is shown in the Command Window.
    🔗
    Solution.
    Running the script produces c = 5 in the Command Window and adds a, b, and c to the Workspace. This illustrates how the Editor and Command Window work together.
    🔗
    🔗
    🔗
    🔗
    🔗

    Extended.

    2. Customize and Restore the Layout.

    Experiment with the MATLAB Desktop layout:
    🔗
    1. Hide the Workspace panel by clicking its close button.
      🔗
    2. Drag the Command Window to a different position on screen.
      🔗
    3. Restore the default layout using the “Home” tab, “Layout” dropdown, and selecting “Default”.
      🔗
    Write a brief description (as a MATLAB comment) of what changed when you restored the default layout.
    🔗
    % Description of what happened when the default layout was restored:
%
    Solution.
    Restoring the default layout resets all panels to their original positions and makes hidden panels visible again. This is useful if the desktop becomes disorganized during customization.
