    Subsection The switch Statement

    The switch statement is another option for controlling conditional flow in MATLAB. It is best when you are comparing one value to a list of exact matches.
    🔗

    The switch Statement.

    The general structure of a switch statement is:
    🔗
    switch myVar
	case val1
		blockA	% ⬅ runs if myVar's value equals val1
	case {val2, val3}
		blockB	% ⬅ runs if myVar's value equals val2 OR val3
	case val4
		blockC	% ⬅ runs if myVar's value equals val4
	otherwise
		blockD	% ⬅ runs if no cases match (default)
end
    where
    • Case values are checked in order from top to bottom.
      🔗
    • The otherwise block runs only when no cases match.
      🔗
    • The otherwise block is optional.
      🔗
    • When there is only one case value, curly braces { } are optional.
      🔗
    • Case values can be numbers, strings, or other data types that support equality comparisons.
      🔗
    • Case values are case-sensitive when comparing strings.
      🔗
    • Case values must be unique; duplicate case values will cause an error.
      🔗
    • You may use as many case blocks as you like.
      🔗
    🔗
    Limitations:
    • Case values cannot use logical operators (e.g., <, >, ==, &, |).
      🔗
    • Switch statements are not suitable for range-based conditions (e.g., checking if a value is between two numbers).
      🔗
    🔗
    🔗
    The switch statement is similar to the if statement, but offers a few advantages. First, it is easier to read; second, it is better when comparing strings (of possibly different lengths).
    🔗

    Checkpoint 3.27.

    (a)

    (i) Switch keywords and roles.
      Match each switch keyword to its role.
      🔗
      A switch block tests one expression, each case provides a value to match, and otherwise provides the default path before end closes the block.
    • switch
    • Starts the block and names the expression to compare.
    • case
    • Runs when the expression matches a listed value.
    • otherwise
    • Runs when no case matches.
    • end
    • Closes the switch statement.
    🔗
    🔗

    (b) Switch vs if-elseif for exact matches.

    When is a switch statement more suitable than an if-elseif-else chain? Select all that apply.
    🔗
    • When comparing a single variable to multiple exact values.
    • The switch statement is designed for testing one variable against a list of specific values.
    • When you need to test ranges like x > 10.
    • Switch statements cannot use logical operators or ranges; use if-elseif for range-based conditions.
    • When comparing string values of different lengths.
    • Switch statements handle string comparisons cleanly, especially when strings have different lengths.
    • When the case values need to be computed at runtime.
    • Case values must be hard-coded constants, not variables or expressions.
    🔗

    (c) Otherwise block is optional in switch.

      The otherwise block in a switch statement is optional.
      🔗

    • True.

    • While the otherwise block is optional, including it provides a default action when no cases match, which can help prevent unintended behavior.

    • False.

    • While the otherwise block is optional, including it provides a default action when no cases match, which can help prevent unintended behavior.
    🔗
    🔗

    Checkpoint 3.28.

    Every switch block in MATLAB must be closed with which keyword?
    🔗
    • end
    • Correct. All MATLAB control structures close with end.
    • endswitch
    • MATLAB uses end, not endswitch.
    • break
    • break exits loops, not switch blocks.
    • return
    • return exits a function, not a switch block.
    🔗

      🔗

      In MATLAB, if one case matches, execution continues into the next case automatically.
      🔗

    • True.

    Checkpoint 3.31.

    To match a switch expression against either 2 or 4, you would write:
    🔗
    • case {2, 4}
    • Correct. A cell array groups multiple match values in one case.
    • case 2 || 4
    • Logical OR is not used inside a case statement.
    • case 2 or 4
    • or is not valid syntax inside a case clause.
    • case 2, 4
    • The values must be wrapped in a cell array {}.

    🌌 Example 3.32. Day Name from Number.

    Display the name of the day corresponding to a day number.
    🔗
    day = 3;
switch day
    case 1
        disp('Monday')
    case 2
        disp('Tuesday')
    case 3
        disp('Wednesday')
    case 4
        disp('Thursday')
    case 5
        disp('Friday')
    otherwise
        disp('Weekend')
end
    Output: Wednesday
    🔗
    🔗

    🌌 Example 3.33. Switch on a String.

    Switch statements work on strings as well as numbers.
    🔗
    color = 'red';
switch color
    case 'red'
        disp('Stop')
    case 'yellow'
        disp('Caution')
    case 'green'
        disp('Go')
    otherwise
        disp('Unknown color')
end
    Output: Stop
    🔗
    🔗

    🌌 Example 3.34. Grouping Cases with a Cell Array.

    Classify a month number as belonging to a season.
    🔗
    month = 4;
switch month
    case {12, 1, 2}
        disp('Winter')
    case {3, 4, 5}
        disp('Spring')
    case {6, 7, 8}
        disp('Summer')
    case {9, 10, 11}
        disp('Fall')
end
    Output: Spring
    🔗
    🔗

    Checkpoint 3.35.

    What does the following code print when x = 7?
    🔗
    x = 7;
switch x
    case {1, 3, 5, 7, 9}
        disp('odd')
    case {2, 4, 6, 8, 10}
        disp('even')
    otherwise
        disp('out of range')
end
    • odd
    • Correct. 7 is in the first case list.
    • even
    • 7 is not in the even list.
    • out of range
    • 7 matches the first case, so otherwise does not run.
    • Nothing is printed.
    • The first case matches, so it executes.
