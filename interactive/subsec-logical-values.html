    Subsection Logical Values

    Before MATLAB can make a decision, it needs a way to represent the answer to a yes-or-no question. Those answers are called logical values: true and false. They are the foundation of every conditional statement you will write.
    🔗
    So far, we’ve written code that runs step by step in a straight line. Real programs need to react to data or user input, choosing different actions when conditions change.
    🔗
    MATLAB has two logical values: true and false. When displayed, they often appear as logical 1 and logical 0. Although they behave similarly to the numeric values 1 and 0, they are different data types. Just as numbers can be stored in variables, logical values can be stored in variables as well.
    🔗

    Logical Values in MATLAB.

    MATLAB has two logical values: true and false. When displayed, they often appear as logical 1 and logical 0. Although they behave similarly to the numeric values 1 and 0, they have a different data type: logical instead of double.
    🔗
    a = true;    % logical value: true
b = false;   % logical value: false
    Key rules:
    • Logical values are of type logical, not double.
      🔗
    • true and 1 display the same but are different data types.
      🔗
    • false and 0 display the same but are different data types.
      🔗
    • Use whos to inspect variable class and memory usage.
      🔗
    🔗
    🔗
    Just as numbers can be stored in variables, logical values can be stored in variables as well. The code below stores both numeric and logical values so you can compare them:
    🔗
    a = 1;
b = true;
c = 0;
d = false;

fprintf("a = %g,  b = %g,  c = %g,  d = %g\n", a, b, c, d)
    Running the above code, fprintf produces the following output:
    🔗
    a = 1,  b = 1,  c = 0,  d = 0
    Even though a and b (and c and d) look the same, MATLAB treats them differently. You can get more information using the whos command. Here is the output you should see:
    🔗
    Name        Size            Bytes  Class      Attributes
a           1x1                 8  double
b           1x1                 1  logical
c           1x1                 8  double
d           1x1                 1  logical
    This shows us two differences:
    Class (data type)
    🔗
    a is a double, while b is a logical.
    🔗
    Bytes (memory usage)
    🔗
    a uses 8 bytes, while b uses 1 byte.
    🔗
    The double data type is meant to store numeric quantities, while the logical data type stores yes/no answers to questions.
    🔗

    Exercises 🤔💭 Conceptual Questions

    1.

    (a)
      In MATLAB, true and 1 are the same data type.
      🔗

    • True.

    • False. While true displays as 1, it is of type logical, not double. They have different data types even though they display the same way.

    • False.

    • False. While true displays as 1, it is of type logical, not double. They have different data types even though they display the same way.
    🔗
    (b) Understanding Logical Values.
    Why is true (logical) different from 1 (double) in MATLAB, even though they display similarly?
    🔗
    • true represents a logical value, while 1 is numeric
    • Correct! Logical values are designed to represent yes/no answers to questions, while numeric values represent measurements or counts.
    • They are the same and can be used interchangeably
    • Incorrect. While they behave similarly in many contexts, they are different data types with different purposes.
    • Logical values are faster than numeric values
    • Incorrect. While logical values do use less memory, the key difference is their purpose: answering yes/no questions versus storing numeric data.
    🔗
    (c)
    Which of the following correctly describes the difference between true (logical) and 1 (double)?
    🔗
    • true represents a yes/no answer; 1 represents a numeric quantity.
    • Correct! Logical values are designed for yes/no answers, while numeric values represent measurements or counts.
    • They are identical and can be used interchangeably in all contexts.
    • Incorrect. While they often behave similarly, they are different data types with different purposes.
    • true uses more memory than 1.
    • Incorrect. A logical value uses 1 byte; a double uses 8 bytes. Logical values use less memory.
    • MATLAB displays true as true and 1 as 1.
    • Incorrect. Both true and 1 are displayed as 1 when used with fprintf.
    🔗
    (d)
    Which MATLAB command displays the class (data type) and memory size of all variables in the workspace?
    🔗
    • whos
    • Correct! whos lists every variable with its size, byte count, and class.
    • disp
    • disp prints the value of a variable but does not show its type or memory usage.
    • class
    • class returns the data type of a single variable but does not list the whole workspace.
    • size
    • size returns the dimensions of an array, not the data type.
    🔗
    🔗
    🔗

    🌌 Example 3.1. Storing and Displaying Logical Values.

    The following example shows how logical values are stored and how they differ from numeric values when inspected with whos:
    🔗
    isRaining = true;
temperature = 22;

whos isRaining temperature
    Expected output:
    🔗
    Name            Size    Bytes  Class      Attributes
isRaining       1x1         1  logical
temperature     1x1         8  double
    Notice that isRaining is of type logical and uses only 1 byte, while temperature is of type double and uses 8 bytes.
    🔗
    🔗

    🌌 Example 3.2. Logical Values in Arithmetic.

    MATLAB allows logical values to participate in arithmetic expressions, treating true as 1 and false as 0. This can be useful for counting:
    🔗
    a = true;
b = false;

fprintf("a + b = %g\n", a + b)   % 1 + 0 = 1
fprintf("a * 5 = %g\n", a * 5)   % 1 * 5 = 5
fprintf("b * 5 = %g\n", b * 5)   % 0 * 5 = 0
    While this works, keep in mind that the result of arithmetic on logical values is of type double, not logical.
    🔗
    🔗
