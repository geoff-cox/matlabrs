    (k)

    Write a function, binomialCoeff, that computes \(n\) choose \(m\) (the binomial coefficient) using the formula:
    \begin{equation*} \binom{n}{m} = \frac{n!}{m!(n-m)!}\text{.} \end{equation*}
    Use a for loop. Assume \(n\) is a nonnegative integer and \(m\) is a non-negative integer less than or equal to \(n\text{.}\)
    🔗
    To code this with one for loop, expand \(n!\) down to \((n-m)!\text{:}\)
    \begin{equation*} n(n-1)(n-2)\cdots(n-(m-1))(n-m)! \end{equation*}
    then cancel the \((n-m)!\) in the numerator and denominator to get:
    \begin{equation*} \binom{n}{m} = \frac{n(n-1)(n-2)\cdots(n-(m-1))}{m(m-1)(m-2)\cdots 1} \end{equation*}
    But this is the same as:
    \begin{equation*} \binom{n}{m} = \frac{n}{m}\cdot\frac{n-1}{m-1}\cdot\frac{n-2}{m-2}\cdots\frac{n-(m-1)}{1} \end{equation*}
    This way, you can compute each fraction for \(k=0,1,2,\ldots,m-1\text{.}\)
    🔗
    Inputs:
    n (1x1) double — nonnegative integer
    🔗
    m (1x1) double — non-negative integer less than or equal to \(n\)
    🔗
    Outputs:
    bicoeff (1x1) double — the binomial coefficient \(\binom{n}{m}\)
    🔗
    Test Cases ⤵︎
    🔗
    bcoef = binomialCoeff(5, 2)
bcoef = binomialCoeff(0, 0)
bcoef = binomialCoeff(7, 7)
bcoef = binomialCoeff(10, 3)
    Expected ⤵︎
    🔗
    % bcoef = 10 (5!/(2!*(5-2)!))
% bcoef = 1 (0!/(0!*0!))
% bcoef = 1 (7!/(7!*0!))
% bcoef = 120 (10!/(3!*7!))

    (o)

    Let \(y(x)\) be the solution to the differential equation:
    \begin{equation*} y' = 2y-2xy, \quad y(0) = y_0\text{.} \end{equation*}
    In this form, the right-side of the equation gives the slope of the tangent line of \(y(x)\) (i.e., the direction of \(y\)) at any point \((x,y)\text{.}\)
    🔗
    For example, to get the direction of \(y(x)\) at the point \((3,1)\text{,}\) we plug \(x=3\) and \(y=1\) into \(2y-2xy\) to get \(m=2\cdot 1 - 2\cdot 3 \cdot 1 = -4\text{.}\)
    🔗

		end
		steps = steps + 1;

	phi = (1 + sqrt(5)) / 2;
	phi_n = 1;
	steps = 0;

	while abs(phi_n - phi) > tol
		phi_n = 1 + 1 / phi_n;
		steps = steps + 1;
	end
end
