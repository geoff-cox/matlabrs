    Subsubsection Drills

    Checkpoint 5.23. Expand the while-loop.

    Expand each while-loop into equivalent repeated code. Write out each iteration as if there were no loop at all, including the condition check at each step.
    🔗
    (a)
    x = 1;
while x < 10
	x = x * 2;
end
fprintf('x = %d\n', x)
    When done, evaluate and confirm it prints x = 16.
    🔗
    🔗
    (b)
    n = 100;
count = 0;
while n >= 10
	n = floor(n / 10);
	count = count + 1;
end
fprintf('count = %d\n', count)
    When done, evaluate and confirm it prints count = 2.
    🔗
    🔗
    (c)
    total = 0;
k = 5;
while k >= 1
	total = total + k;
	k = k - 2;
end
fprintf('total = %d\n', total)
    When done, evaluate and confirm it prints total = 9.
    🔗
    🔗
    (d)
    a = 30;
b = 12;
while b ~= 0
	r = mod(a, b);
	a = b;
	b = r;
end
fprintf('a = %d\n', a)
    When done, evaluate and confirm it prints a = 6.
    🔗
    🔗

    Checkpoint 5.24. Rewrite the for-loop as a while-loop.

    Every for-loop can be rewritten as a while-loop. The pattern is:
    🔗
    \(\)
    🔗
    for-loop ⤵︎
    🔗
    for k = start:step:stop
	loop_body
end
    Equivalent while-loop ⤵︎
    🔗
    k = start;
while k <= stop
	loop_body
	k = k + step;
end
    For each for-loop below, rewrite it as an equivalent while-loop. Replace each ? with the appropriate code.
    🔗
    (a)
    total = 0;
for k = 1:5
	total = total + k;
end
fprintf('total = %i\n', total)
    When done, evaluate and confirm it prints total = 15.
    🔗
    🔗
    (b)
    product = 1;
for k = 2:2:10
	product = product * k;
end
fprintf('product = %i\n', product)
    When done, evaluate and confirm it prints product = 3840.
    🔗
    🔗
    (c)
    for n = 10:-3:1
	fprintf('%d, ', n)
end
fprintf('\n')
    When done, evaluate and confirm it prints 10, 7, 4, 1,.
    🔗
    🔗
    (d)
    count = 0;
n = 20;
for k = 1:n
	if mod(k, 4) == 0
		count = count + 1;
	end
end
fprintf('count = %i\n', count)
    When done, evaluate and confirm it prints count = 5.

    🔗

    Checkpoint 5.26. Halving until below 1.

    Put the blocks in order to create a script that starts with x = 100 and repeatedly halves it until x drops below 1. Count and print the number of halvings.
    🔗
    Use correct indentation to show which lines are inside the loop.
    🔗
    x = 100;											
count = 0;										
---
while x >= 1							
---
	x = x / 2;									
	count = count + 1;					
---
end													
---
fprintf('count=%i\n',count)
    🔗

    Checkpoint 5.27. Sum until threshold.

    Put the blocks in order to create a script that adds \(1 + 2 + 3 + \cdots\) until the total first reaches or exceeds 50 and print the last integer added.
    🔗
    Use correct indentation to show which lines are inside the loop.
    🔗
    total = 0;						
k = 0;								
---
while total < 50	
---
	k = k + 1;					
	total = total + k;	
---
end									
---
fprintf('k=%i\n',k)
    🔗

    Checkpoint 5.28. Doubling past a target.

    Put the blocks in order to create a script that repeatedly doubles x until it exceeds N. Count how many doublings were performed.
    🔗
    Use correct indentation to show which lines are inside the loop.
    🔗
    x = 3;							
N = 200;						
ct = 0;					
---
while x <= N				
---
	x = x * 2;				
	ct = ct + 1;	
---
end									
---
fprintf('steps=%i\n',ct)
fprintf('⇒ x=%i\n',x)
    🔗

    Checkpoint 5.29. Interest until doubled.

    Place the blocks to construct a function called double that returns how many years it takes for a balance to double given an annual interest rate.
    🔗
    Inputs: r = the interest rate (e.g. 0.05 for 5%), bal = balance.
    Output: yrs = the number of years to double.
    🔗
    Use correct indentation to show which lines are inside the loop.
    🔗
    function yrs=double(bal,r)	
---
	goal = 2 * bal;										
	yrs = 0;													
---
	while bal < goal								
---
		bal = bal + bal * r;						
		yrs = yrs + 1;									
---
	end																
end
