    ans = (3 >= 2) & (3+4 == 6)

    • ans = 0 (logical)
    • Correct! Even though 3 >= 2 is true, the expression 3+4 == 6 is false (since \(3+4=7\)). For an AND operation to be true, both sides must be true.
    • ans = 1
    • Incorrect. The result of a logical operation is always of type logical, not double.

    • Incorrect. MATLAB uses true and false.

    🔗
    • 1 byte
    • Correct! Logical values use only 1 byte, compared to 8 bytes for a double.
    • 8 bytes

    • 4 bytes
    • Incorrect. Logical scalars use 1 byte in MATLAB.
    • 2 bytes

      Logical values in MATLAB can be stored in variables just like numbers.
      🔗

    • False.

    (p) Class of a logical value.

    What is the MATLAB class of the variable x after x = false?
    🔗
    • logical
    • Correct! Assigning false creates a variable of class logical.
    • double
    • Incorrect. false creates a logical, not a double.
    • int
    • Incorrect. MATLAB does not have a class named int for this purpose.
    • boolean
    • Incorrect. MATLAB calls this type logical, not boolean.

    (q) Arithmetic with logical values.

    What does MATLAB print after fprintf('%g\n', true + true)?
    🔗
    • 2
    • Correct! true acts as 1 in arithmetic, so true + true = 2.
    • true
    • Incorrect. MATLAB does not print the word true with fprintf('%g', ...).
    • 1
    • Incorrect. Adding two true values gives 2, not 1.
    • An error occurs.
    • Incorrect. Logical values can participate in arithmetic; no error is raised.

    • True.

    • False. MATLAB allows logical values in arithmetic, treating true as 1 and false as 0.

    2. Assignment vs. Comparison.

    Which operator tests whether two values are equal?
    🔗
    • ==
    • Correct! Double equals tests equality.
    • =
    • Single equals assigns a value; it does not compare.
    • ~=
    • This tests for inequality (not equal), not equality.
    • =>
    • This is not a valid MATLAB operator. Greater-than-or-equal uses >=.
    🔗

      An AND operation (&) returns true if at least one of the conditions is true.
      🔗

    • True.

    • False. AND requires both conditions to be true. You are thinking of OR (|), which returns true if at least one is true.

    • False.

    • False. AND requires both conditions to be true. You are thinking of OR (|), which returns true if at least one is true.

    4. Result of a comparison.

    What is the value of p after p = (10 > 5)?
    🔗
    • 1 (logical)
    • Correct! Since 10 is greater than 5, the expression evaluates to true, which displays as 1.
    • 0 (logical)
    • Incorrect. 10 is greater than 5, so the result is true.
    • 1 (double)
    • The numeric value is correct, but the class is logical, not double.
    • An error occurs.
    • No error. This is a valid comparison that produces a logical result.

    5. Negation result.

    What does ~(3 > 5) evaluate to?
    🔗
    • 1 (true)
    • Correct! 3 > 5 is false, and NOT false is true.
    • 0 (false)
    • Incorrect. 3 > 5 is false; negating it gives true.
    • An error occurs.
    • No error. The NOT operator negates any logical value.
    • -1
    • Incorrect. NOT produces true or false, not -1.
    🔗

    6.

      The expression x <= 10 is equivalent to ~(x > 10).
      🔗

    • True.

    • True. "Not greater than 10" is the same as "less than or equal to 10."

    • False.

    • True. "Not greater than 10" is the same as "less than or equal to 10."

    7. AND evaluation.

    Given x = 5, what does (x > 0) & (x < 3) evaluate to?
    🔗
    • 0 (false)
    • Correct! While 5 > 0 is true, 5 < 3 is false. AND requires both to be true.
    • 1 (true)
    • Incorrect. 5 < 3 is false, so the AND expression is false.
    • An error occurs.
    • No error. This is a valid logical expression.
    • 5
    • Incorrect. Logical expressions produce 0 or 1, not the value of x.
    🔗

    8. OR evaluation.

    Given x = 5, what does (x < 0) | (x > 4) evaluate to?
    🔗
    • 1 (true)
    • Correct! Although 5 < 0 is false, 5 > 4 is true. OR requires only one to be true.
    • 0 (false)
    • Incorrect. 5 > 4 is true, so the OR is true.
    • An error occurs.
    • No error. This is a valid logical expression.
    • 2
    • Incorrect. Logical expressions produce 0 or 1.
    🔗

    9. Precedence: NOT before AND.

    How does MATLAB interpret ~A & B?
    🔗
    • (~A) & B
    • Correct! NOT has higher precedence than AND, so A is negated first.
    • ~(A & B)
    • Incorrect. NOT applies only to A, not to the whole AND expression.
    • A & (~B)
    • Incorrect. The NOT operator is placed before A, so it negates A, not B.
    • This causes an error.
    • No error. This is valid MATLAB syntax.
    🔗

      In MATLAB, A & B | C is evaluated as A & (B | C).
      🔗

    • True.

    • False. AND has higher precedence than OR, so it is evaluated as (A & B) | C.

    • False.

    • False. AND has higher precedence than OR, so it is evaluated as (A & B) | C.

    • <>
    • Incorrect. MATLAB does not use <>; use ~=.
    • =/=
    • Incorrect. Use ~= for inequality in MATLAB.
