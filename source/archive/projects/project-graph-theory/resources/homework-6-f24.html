Function:  HW6P5_construct_directed_graph_lastname.m
Description:  This function constructs a directed graph structure from a given set of vertices and edges. It also computes the graph properties listed in the output details below. 
Inputs:  vertices (n x 1, integer): A list of vertex IDs.
  edges (m x 2 or m x 3, integer): A list of edges where each row contains the starting and ending vertex IDs.
  graph_name (string): A name for the graph stored as part of the output structure.
Outputs:  G (struct): A structure representing the graph containing the following fields:
 
  1. G.name (string): The name of the graph as provided in graph_name.
  2. G.vertices (n x 1, integers): List of vertex index IDs
  3. G.edges (m x 3): A matrix where each row represents an edge connecting two vertices.
  4. G.n (integer): The number of vertices in the graph.
  5. G.m (integer): The number of edges in the graph.
  6. G.adj_mat (n x n double array): The adjacency matrix of the graph.
  7. G.cost_mat (n x n double array): The cost/weight matrix of the graph.
  8. G.out_degrees (n x 1, integers): List of vertex out-degrees.
  9. G.in_degrees (n x 1, integers): List of vertex in-degrees.
Note: The values of the fields 6 through 9 should come from the output of HW6P1 - HW6P4, respectively.
Comments:  If the edges matrix is input without weights (i.e., a 3rd column), give each edge a default weight of 1.
