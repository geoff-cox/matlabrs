Function:  HW7P1_create_keyboard_struct_lastname.m
Description:  In the Wordle game, the user will click on the "keyboard" at the bottom of the game board.
 
  As the user plays the game, the boxes on the keyboard change color accordingly, as shown below.
 
  This function creates the structure we use to store information about the keyboard.  In particular, this structure has 26 fields, one for each letter in the alphabet, as shown.
 
  Each letter contains another structure that has three fields:
 
  • xvals contains the x-coordinates of the boundary box for that letter.
  • yvals contains the y-coordinates of the boundary box for that letter.
  • color contains the code for the color in that box.  The default value is grey, which we get with the RGB triplet [0.5, 0.5, 0.5].
  For example, consider the picture below of the struct associated with the letter T on the keyboard.
 
  Notice that the box containing T has corners at the points (8,4), (10,4), (10,6), and (8,6).  Note how the xvals and yvals correspond to these coordinates.
  Here's one final example, for the letter N on the keyboard.  Notice that the color field has 'g' (for green).
 
Inputs: none
Outputs: keyboard (struct) is a structure containing 26 fields (one for each letter); each of the letters contains a struct with three fields
Comments: Note that this function does not display the game board or the keyboard.  No plot/figure is involved in this function. The purpose of this function is only to create the keyboard structure.
  A template is provided that generates the top two lines of the keyboard. You should create the code to complete the keyboard structure.

Function:  HW7P4_update_colors_in_structs_lastname.m
Description:  As the Wordle game is played, the user makes a guess, and the feedback the user has before they make their next guess is provided in the form of colors that appear in two places: on the guess boxes and on the keyboard. This function takes in the colors (as a five-letter string) that should appear in the guess boxes on the game board, and then updates the colors stored in the both the guess_box structure and the keyboard structure.
Inputs: guess_boxes (65 struct with 4 fields) as described previously
  keyboard (struct) is a structure containing 26 fields (one for each letter); each of the letters contains a struct with three fields; described in detail previously
  attempt_num (double) is a number that indicates how many guesses the user has made
  colors (string) is a five-letter string representing the guess box colors associated with the current guess; the only letters in the string are w, g, and y (because the only colors that should appear in the guess boxes are white, green and yellow).
Outputs: guess_boxes (struct)
  keyboard (struct)
Comments: Note that this function does not display the game board or the keyboard.  No plot/figure is involved in this function. The purpose of this function is to edit the appropriate color fields in the guess_boxes and  keyboard structures.
  However, it's easiest to test this function by displaying the game board with the given inputs and then displaying the game board after the function has been run. Some sample inputs are provided in this .mat file. You may also wish to use this script for testing.
