Function:  HW5P1_better_ai_move_lastname
Description:  This program returns an AI move to an available space in a Tic-Tac-Toe game based on the following strategy:
  Priority 1: If a winning move is available, it takes it.
  Priority 2: If a winning move for the opposing player is available, it takes it (thus blocking that move).
  Priority 3: It selects a space at random.  That is, it uses the dumb_ai_move strategy. 
Inputs:  state (1 x 1) struct object containing the state of the current tic-tac-toe game. 
Outputs:  selection (1 x 1)  The absolute index of the chosen space.
Comments:  This is a slightly smarter version of your dumb_ai_move code.
  If there are multiple winning move spaces available, take the space with the lowest absolute index. 
Examples:  Running 
game_state.data = [ 0 -1  1; ...
                   -1  1 -1; ...
                    1  1 -1 ];
game_state.player = 1;
game_state.empty_space = [1 0 0 0 0 0 0 0 0];
selection = HW5P1_better_ai_move(game_state)
should return
  selection = 1  (only choice)
  Running
  
game_state.data = [ 0  1 -1; ...
                    1  1  0; ...
                   -1 -1  0 ];
game_state.player = 1;
game_state.empty_space = [1 0 0 0 0 1 0 1 0];
selection = HW5P1_better_ai_move(game_state)
  should return
  selection = 8  (winning move for X)
  Running
  
game_state.data = [ 0  1 -1; ...
                    1  1  0; ...
                   -1  0 -1 ];
game_state.player = 1;
game_state.empty_space = [1 0 0 0 0 1 0 1 0];
selection = HW5P1_better_ai_move(game_state)
  should return
  selection = 6  (both 6 and 8 are winning moves for X; return the smallest)
  Running
  
game_state.data = [ 1  0 -1; ... 
                    0  1  0; ...
                    0  0  0 ];
game_state.player = -1;
game_state.empty_space = [0 1 1 1 0 1 0 1 1];
selection = HW5P1_better_ai_move(game_state)
  should return
  selection = 9 (O doesn't have a winning move but blocks X's winning move)

Function:  HW5P3_pvp_game_loop_lastname.m
Description:  This program implements the game loop for a player-versus-player (PVP) version of Tic-Tac-Toe.
Inputs:  state (1 x 1) struct object containing the initial state of a PVP Tic-Tac-Toe game. 
Outputs:  state (1 x 1) struct object containing the final state of a PVP Tic-Tac-Toe game.

  The game loop should repeat at most nine rounds of a Tic-Tac-Toe game.

  • Update the game interface,
  • Check for a winner.
  This program should return an updated game_state structure containing the game's results.
