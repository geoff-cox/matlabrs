Function:  HW8P4_is_new_vertex_valid_lastname.m
Description: 
This program determines if the x and y value of the user's mouse click is a valid vertex for the polygon. In this case, valid means the new edge formed from the last vertex in the collection to the new vertex would not intersect with any of the current edges of the partially constructed polygon. 
Inputs: vx (integer) x-value of a potential new vertex (rounded from the user mouse click).
  vy (integer) y-value of a potential new vertex (rounded from the user mouse click).
  vertices (1 x N struct with 2 fields) structure array containing a complete or partial set of the vertices (x and y-values) of a polygon.
Outputs: valid (logical) : is true if the new mouse click is a valid vertex. Is false, otherwise. 
Comments: There are two special cases of this program that you should be aware of:
 
  • If there is only one vertex in vertices, then any new vertex is valid as long as it is not equal to the first vertex.
  • If there are two or more vertices in vertices, then the edge connecting the previous vertex in vertices to the new vertex must share a vertex. Keep this in mind when checking if the new edge intersects with any of the current edges of the polygon.
  You may find your HW8P2_is_pt_on_line_segment and HW8P3_do_line_segments_intersect codes helpful here.

Script:
HW8_polygon_area_part_1_version_lastname.m
Description:
 This script creates an interface for a user to click on that allows them to build a simple polygon by specifying the locations of the vertices.
  Your script should have two main sections: 
  Section 1: Set-up.
  This section should perform the following tasks:
 
  • Define variables that store the minimum and maximum values for the x and y-values of the figure.
  • Defines a variable that stores the max number of allowable vertices (set the value to 25).
  • Pre-allocates the 1 x N vertices structure array where N is the max number of allowable vertices. 
  • Defines a variable that tracks the number of vertices that have been added to the polygon.
  • Display the initial interface to the user.
  Section 2: User Interaction (building the polygon).
  This section should perform the following tasks:
 
  • Get the first vertex (mouse click) from the user.
  • Rounds this x and y value to the nearest whole number and adds it to the vertices structure array.
  • Plots the first vertex
  • Use a loop to
    • get a new vertex,
    • round it,
    • check to see if it closes the polygon,
    • if it can be added, add it to the collection of vertices and plot the vertex and new edge.
  • Stop looping if
    • the user closes the polygon by clicking on the first vertex for a second time, or
    • the max number of vertices was reached. In this case, make sure the final edge also gets plotted.
  Note: A polygon must have at least 3 vertices. Therefore, the user can "close" a polygon only after 3 vertices have been selected.
  Section 3: Post Interaction.
  This section should perform the following tasks:
 
  • Fill the completed polygon with a transparent color.  To get a transparent color you can use the 'FaceAlpha' parameter of the fill command.
Comments: The tasks listed above are guidelines for the general structure of your script. The details are left to you.
