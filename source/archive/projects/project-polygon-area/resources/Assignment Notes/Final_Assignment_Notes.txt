New MATLAB commands

    If a struct array has a numeric field, how do you put all the different 
    values of that field into a vector?
    
    For example,
    
    poly(1).x = 5;
    poly(2).x = -1;
    poly(3).x = 6;
    poly(4).x = 10;
    
    then you can store all the x-values in a vector using the command:
    
    >> xvals = [poly.x]

    xvals = [5 -1 6 10] 
    
    In short, the brackets convert multiple field values into a vector.
