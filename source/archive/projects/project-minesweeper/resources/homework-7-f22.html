Description: Write a script that plays a game of tic-tac-toe with a graphical interface.
Directions: When you click run, your script should perform the following tasks:
 
  • Display welcome message to MATLAB's command window.  Use fprintf.
  • Define your game state variables (examples: game_state, winner, player, moves, etc.)
  • Using input, prompt the user for the number of players (options: 0,1, or 2).
    • If the number of players is 0, prompt the user to select the AI ability level for X (options: 1, 2, or 3) and then the AI ability level for O (options: 1, 2, or 3).
    • If the number of players is 1, prompt the user to select if they will be X (move first) or O, then prompt them to select the AI ability level for their opponent.
    • If the number of players is 2, no other input is needed and the game should begin.

    figure('Position',[100,100,650,600]);

    ax = gca; ax.XColor = 'none'; ax.YColor = 'none';

  • When the game is complete, post a message about the outcome of the game in the title of the plot. Use the title command.
Comments: If you want a short pause between AI moves in the AI vs AI mode, you can use MATLAB's pause command.
