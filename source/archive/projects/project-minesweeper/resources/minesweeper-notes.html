Minesweeper Note #1 Scaling the gameboard

It is important to scale the size of your figure (containing the gameboard) according to the size of the grid. This allows the font size of the text on your gameboard to be consistent.

I found that 50 pixels per grid space to be a good scaling.

If you want to do this, then inside your MS_display_interface code define your figure position with the following values:  

fig = figure('Position',[10,10,50*(N+2),50*(N+2)]);

where the gameboard is N x N.  If you don't pad your gameboard with a border, you shouldn't need the +2 above. 

 Minesweeper Note #2 flag and skull icons

You are free to choose any character to represent flags and mines, but the ones I used were char(9873) and char(9760), respectively.

 Minesweeper Note # 3 Toggling the flag

When a player clicks on the bottom-left quadrant of a game space, the space will be flagged. If the player clicks on the bottom-left quadrant of a flagged space, it should remove the flag.  In my code, I toggle this by changing the rectangle FaceColor with the original color. This "hides" the flag behind it.  You can also use the delete command, but this requires defining the text as a variable. For example,

txt = text(4,3,char(9873));
delete(txt);

creates a flag at the point (4,3), then deletes it.
