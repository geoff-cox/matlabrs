Function:  get_spaces_to_reveal
Description:  This program returns all the spaces that need to be reveal following a valid left-click. This is easily the most challenging program of the assignment and is the program for those seeking an A in the class. If you haven't finished the other helper functions, do those first to optimize your homework grade.
Inputs:   x (1 x 1) integer representing the x-coordinate of the lower left corner of a given space.
  y (1 x 1) integer representing the y-coordinate of the lower left corner of a given space.
  state (1 x 1) struct object representing the current game state.  
Outputs:  reveal_list (K x 2) two-column matrix containing the x and y coordinates of the lower-left corner of every space that should be revealed. 
Comments:  Think about what spaces are revealed after a "valid" left-click.
  Play the demo again to refresh your memory.
  This function does not update the game state in any way.  It only generates a list of spaces that need to be revealed.
  This function can assume the following:
 
  1. A click was received and stored in state.last_x and state.last_y.
  2. The click is valid (i.e. in range and not revealed)
  3. The click was a left-click.
  Therefore, you do not need to check any of the things above.
  Possible Strategy:
  First of all, if the data value of the clicked space is not 0, then the only thing to return is the last x and y click. DONE. Therefore, we will only discuss the strategy when the data value is zero.
  Assuming the value is zero then all neighbors of the clicked space should be revealed if (a) they have not already been revealed and (b) the space is not flagged. The tricky part is that if a neighbor also has a zero data value then all if it's neighbors also need to be revealed. This keeps chaining until no more neighbors have zero data values.
  So I think it will be helpful to introduce two variables.
 
  • A N x 2 matrix, called chain, that contains all the locations that are connected to the current chain and have to eventually be added to the revealed_list output. 
  • A copy of the current state.revealed matrix. We can call it explored for this discussion. This will track which spaces got added to the  revealed_list already. This will help prevent duplicate values.
  Strategy:
 
  • Start by adding original clicked value to the chain and mark it as being explored.
  • As long as the chain still has values, repeat the following:
    • Get the data value of the location on the top of the chain.
    • if it is zero, then do the following:
      • get the neighbors of this location.
      • for each neighbor
        • if the neighbor has not been explored, then add it to the chain and mark it as explored.
    • if the top location on the chain has not been flagged, then add it to the revealed_list.
    • delete the top location on the chain.
