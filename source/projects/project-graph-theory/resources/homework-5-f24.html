Function:  HW5P2_incidence_matrix_lastname.m
Description:  This function constructs the incidence matrix for an undirected graph represented by the structure G. The incidence matrix represents the connections between vertices and edges, with rows corresponding to vertices and columns to edges. For each edge, the matrix contains values indicating which vertices are connected by that edge.
Inputs:  G (struct): A structure representing the graph containing, at minimum, the following fields:
 
  • G.n (integer): The number of vertices in the graph.
  • G.m (integer): The number of edges in the graph.
  • G.edges (m x 2): A matrix where each row represents an edge connecting two vertices.
Outputs:  I (n x m): The incidence matrix, where each row represents a vertex, each column an edge, and each element indicates whether a vertex is incident to an edge:
 
  • If vertex i i is incident to edge e e , then I ( i , e ) = 1 I(i, e) = 1
  • If vertex i i is not incident to edge e e , then I ( i , e ) = 0 I(i, e) = 0
Comments:  Your function should handle cases with no edges (empty edge list).
  For self-loops, only a single 1 should be assigned in the row of the vertex in the column corresponding to the edge.
