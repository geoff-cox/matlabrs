Graph Theory Reference Handout

Definitions

  1. Graph: A graph G=(V,E)G = (V, E) is a collection of vertices VV and edges EE connecting pairs of vertices.

  2. Adjacency Matrix: A square matrix where entry Ai,jA_{i,j} represents the number of edges connecting vertex ii to vertex jj. In an undirected graph, this matrix is symmetric.

  3. Incidence Matrix: A matrix where rows represent vertices and columns represent edges. Each entry indicates whether a vertex is incident (connected) to a specific edge.

  4. Degree of a Vertex: The number of edges incident to a vertex. In an adjacency matrix, the degree is the sum of entries in the corresponding row.

  5. Eulerian Graph: A connected graph where each vertex has an even degree, allowing a traversal of every edge exactly once and returning to the starting point (Eulerian circuit).

  6. Simple Graph: A graph with no self-loops (edges connecting a vertex to itself) and no parallel edges (multiple edges between two vertices).

  7. Cycle: A closed path with no repeated vertices, except for the starting and ending vertex. A graph with at least one cycle contains a path that starts and ends at the same vertex without retracing any edges.

  8. Connected Graph: A graph is connected if a path exists between every pair of vertices.

  9. Tree: A connected, acyclic graph (contains no cycles).

  10. Bipartite Graph: A graph whose vertices can be divided into two disjoint sets S1S_1​ and S2S_2​ so every edge connects a vertex in S1S_1​ to one in S2S_2​.

Theorems

  1. Theorem 1: A connected graph is Eulerian if every vertex has an even degree.

  2. Theorem 2: A graph is a tree if it is connected and contains no cycles.
