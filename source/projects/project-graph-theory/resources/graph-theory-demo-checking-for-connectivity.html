Graph Theory Homework Demo

Here's an in-class demonstration for understanding the graph connectivity algorithm in the HW5P8_is_connected function. This function uses a breadth-first search (BFS) approach to check if all vertices in an undirected graph are reachable from any starting vertex, thereby determining if the graph is connected.

Demonstration: Checking Graph Connectivity

Objective

To help students understand how to determine if an undirected graph is connected, meaning there is a path between every pair of vertices in the graph.

Steps in the Algorithm

  1. Initialize Starting Conditions:

    • Choose a starting vertex, mark it as visited, and add it to a queue.

  2. Visit Each Vertex:

    • Dequeue a vertex from the queue and examine its neighbors (vertices directly connected to it by an edge).
    • For each unvisited neighbor:
      • Mark it as visited.
      • Enqueue it to explore its neighbors in the next steps.

  3. Repeat:

    • Continue dequeuing vertices and exploring their neighbors until the queue is empty, meaning all reachable vertices have been visited.

  4. Check Result:

    • If all vertices are marked as visited, the graph is connected.
    • If any vertex is unvisited after the traversal, the graph is disconnected.

    • Visited array: [true, false, false, false]
    • Queue: [1]

  2. Process Queue:

    • Dequeue 1:

      • Visited array: [true, true, false, false]
      • Queue: [2]

    • Dequeue 2:

      • Neighbors of 2: {1, 3}
      • Vertex 1 is already visited. Mark 3 as visited and enqueue it.
      • Visited array: [true, true, true, false]

      • Neighbors of 4: {3}

  3. Final Check:

    • Since all vertices are marked as visited, the graph is connected.

function result = HW5P8_is_connected(G) % Initialize visited array and queue visited = false(1, G.v_count); queue = 1; % Start with the first vertex % Breadth-First Search (BFS) to explore all reachable vertices while ~isempty(queue) % Dequeue the first element current = queue(1); queue(1) = []; % Remove the processed vertex visited(current) = true; % Get neighbors of the current vertex neighbors = HW5P7_get_neighbors(current, G.adj_mat); % Enqueue unvisited neighbors for neighbor = neighbors if ~visited(neighbor) visited(neighbor) = true; queue(end + 1) = neighbor; % Add neighbor to the end of the queue end end end % Check if all vertices have been visited result = all(visited); % Returns true if connected, false otherwise end

Key Points for Students

  • Queue-Based Traversal: This algorithm relies on the Breadth-First Search (BFS) technique, using a queue to ensure all reachable vertices are visited.
  • Marking Visited Nodes: Helps avoid revisiting vertices and confirms full connectivity by the end of the traversal.
  • Connectivity Check: At the end, verifying that all vertices have been visited ensures that every vertex is reachable from any other vertex.

This demonstration illustrates how a BFS traversal can be used to explore and confirm connectivity in a graph, providing students with insights into both graph theory and algorithmic problem-solving with queues.
