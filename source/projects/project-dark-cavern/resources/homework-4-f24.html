Function:  HW4_initialize_game_v3_lastname.m
Description:  This function sets up the game environment, including the player, the maze structure, and fundamental gameplay elements. The new components are highlighted below.
Inputs:  height (integer): The number of rows in the maze, representing its height.
  width (integer): The number of columns in the maze, representing its width.
Outputs:  maze (struct): A structure containing information about the randomly generated maze. It includes:
 
  • maze.walls: A 2D matrix of size height x width where 1 represents a wall and 0 represents an open path.
  • maze.h: The height of the maze (i.e., the number of rows in the walls matrix).
  • maze.w: The width of the maze (i.e., the number of rows in the walls matrix).
  • maze.exit: A 1x2 vector [row, col] representing the randomly selected exit position.
  • maze.key: A 1x2 vector [row, col] representing the randomly selected key position.
  • maze.torch: A 1x2 vector [row, col] representing the randomly selected torch position.
  • maze.icons: A struct containing the visual symbols used for displaying the maze:
    • maze.icons.wall: Icon for walls ('▓').
    • maze.icons.open: Icon for open paths ('⛆').
    • maze.icons.exit: Icon for the exit ('⛝').
    • maze.icons.player: Icon for the player's appearance ('⛄').
    • maze.icons.key: Icon for the key ('⚿').
    • maze.icons.torch: Icon for the torch ('✨').
    • maze.icons.dark: Icon for unexplored areas ('█' or '▓') 
  player (struct): A structure representing the player's current state. It includes:
 
  • player.position: A 1x2 vector [row, col] representing the player's starting position (fixed at [2, 2]).
  • player.moves: An integer representing the number of moves the player has made (initially 0).
  • player.direction: A character representing the direction the player faces (initially 's' for south).
  • player.has_key: A logical value initialized to false, indicating whether the player has the key.
  • player.has_torch : A logical value initialized to false , indicating whether the player has the torch.
  • player.sight : A height x width logical matrix the same size as the wall matrix (initialized to false), indicating whether a space can be seen.
Comments:  You will need the same generate_maze program as in the previous version.

Description:  This function is responsible for handling the player's movement within the maze. The player's position is updated based on the input direction, provided the new location is not a wall. Additionally, this function handles the player's collection of the key or torch if they move to its location. 
Inputs:  maze (struct): The structure representing the maze. It includes all the fields described in HW4_initialize_game.

  • 's':  Move down.
  • 'a':  Move left.

Outputs:  player (struct): The updated player structure reflects the new position, number of moves, and whether the key has been collected.
Comments:  If necessary, this function should update ALL of the fields of the player structure, including the sight.

Function:  HW4_line_of_sight_v3_lastname.m
Description:  This function determines the visible spaces within a maze from the player's current position. It implements a line-of-sight mechanic, simulating what the player can see based on their position, direction, and whether they possess a visibility-enhancing item (i.e., the torch).
Inputs:  maze (struct): The structure representing the maze. It includes all the fields described in HW4_initialize_game.
  player (struct) - The structure representing the player's current state. It includes all the fields described in HW4_initialize_game.
Outputs:  player (struct): The updated player structure reflects the new position, number of moves, and whether the key has been collected.
Comments:  Only adjacent spaces are visible if the player does not have the torch.
