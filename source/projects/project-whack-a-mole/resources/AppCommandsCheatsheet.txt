App Commands Cheatsheet

delete(app)
    closes the app.
app.ButtonName.Text
    gets the current text on the button, ButtonName.
app.ButtonName.Text = 'Hi';
    sets the text on the button, ButtonName, display 'Hi'.
app.ButtonName.Text = '';
    removes all text on the button, ButtonName.
app.ButtonName.Icon
    gets the active icon on the button, ButtonName.
app.ButtonName.Icon = 'WhackAMoleFace.png';
    sets the icon on the button, ButtonName, display the file WhackAMoleFace.png.
app.LevelEditField.Value
    gets the current value in the edit field, LevelEditField.
app.LevelEditField.Value = 6
    sets the value in the edit field, LevelEditField, to 6.
app.Button_3.Enable = 1
    enables Button_3 allowing the user to interact with it.
app.Button_3.Enable = 0
    disables Button_3 preventing the user from interacting with it.

Other useful MATLAB commands
pause(6)
    pauses code for 6 seconds
strcmp(charArray1,charArray2)
    returns true if charArray1 is equal to charArray2. False otherwise.
