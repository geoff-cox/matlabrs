Data Cleaning and Preprocessing Pipeline

Objective

In this assignment, you will create a data preprocessing pipeline in MATLAB. This pipeline will include handling missing values, removing outliers, normalizing data, and encoding categorical variables. The goal is to implement these steps from scratch, without relying on high-level MATLAB functions.

Assumptions

  • The input dataset may contain missing values (NaNs), numeric and categorical data.
  • Outliers are defined as data points with a Z-score greater than a specified threshold (e.g., 3).
  • Categorical data is represented as strings (e.g., 'red', 'blue', 'green').

Input Variables

  • data: A matrix or cell array containing the dataset. Numeric data should be stored as doubles, and categorical data as strings.
  • categoricalCols: A vector of column indices indicating which columns contain categorical data.
  • threshold: (Optional) A numeric value specifying the Z-score threshold for outlier removal. Default is 3.

Output Variables

  • preprocessedData: The cleaned and preprocessed dataset, ready for further analysis or modeling.

Steps to Implement

  1. Handle missing values by replacing them with the mean of the corresponding column.
  2. Remove outliers based on Z-score thresholding.
  3. Normalize numeric data using min-max normalization.
  4. Encode categorical variables using one-hot encoding.
  5. Combine all the steps into a single preprocessing function.

Hints

Hint 1: To handle missing values, use isnan() to detect NaNs and mean() to calculate the mean of a column, excluding NaNs.

Hint 2: For outlier removal, calculate the Z-score for each element using zscore() or manually compute it using the mean and standard deviation of each column.

Hint 3: For min-max normalization, use the formula: (x - min) / (max - min).

Hint 4: One-hot encoding can be done by iterating over the unique categories in a column and creating binary vectors for each category.

Example Input/Output

Example 1

Input:

data = [1, NaN, 3, 'red'; 
                4, 5, NaN, 'blue'; 
                7, 8, 9, 'green']

categoricalCols: [4]

Output:

preprocessedData = [1, 6.5, 3, 1, 0, 0; 
                          4, 5, 6, 0, 1, 0; 
                          7, 8, 9, 0, 0, 1]

Explanation: Missing values are replaced with the mean of the column, outliers are removed, numeric data is normalized, and categorical data is one-hot encoded.

Example 2

Input:

data = [2, 150, 'small'; 
                3, 300, 'medium'; 
                4, 450, 'large']

categoricalCols: [3]

Output:

preprocessedData = [0, 0, 1, 0, 0;
                          0.5, 0.5, 0, 1, 0; 
                          1, 1, 0, 0, 1]

Explanation: The numeric columns are normalized, and the categorical column is one-hot encoded.

Deliverables

  • A MATLAB script or function file that implements the complete data preprocessing pipeline.
  • Test your function on different datasets and include a short report explaining how your function handles each preprocessing step.
