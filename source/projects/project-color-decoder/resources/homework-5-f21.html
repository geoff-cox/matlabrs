Description: In the color decoder game, after the user completes a guess, they get feedback to help them make their next guess.  This feedback comes in the form of small black or white boxes.

Function:  HW5P2_check_game_over_lastname.m
Description: In the color decoder game, there are two ways the game can end.
 
  • The user's guess can match the secret code, and then the game is over and the user wins.
  • The user can run out of attempts without ever matching the secret code, in which case the game is over and the user does not win.
  This function checks the status of the game and determines whether the game is over and whether the user has won.
Inputs: current_attempt_num (double) is a number that indicates how many guesses the user has made
  num_attempts (double) is a number that indicates the maximum number of attempts allowed
  num_black_feedback_boxes (double) is the number of black feedback boxes associated with the current guess; if num_black_feedback_boxes has a value of four, then the user has successfully found the secret code
Outputs: is_game_over (boolean) is true (or 1) if the game is over and false (or 0) if the game continues
  is_winner (boolean) is true (or 1) if the user has matched the secret code and is false (or 0) if the current guess is not correct
Comments:
Note that if is_winner is true, then is_game_over should also be true.
Examples
INPUT
  4, 6, 4
  OUTPUT
  [1, 1]
  INPUT
  7, 7, 4
  OUTPUT
[1, 1]
INPUT
10, 10, 2
OUTPUT
[1, 0]
INPUT
3, 10, 3
OUTPUT
[0, 0]
